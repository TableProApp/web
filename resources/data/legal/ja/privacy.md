本方針は Mac、Linux、iPhone、iPad の TablePro、tablepro.app、docs.tablepro.app、アカウント、購入、サポート、ニュースレターに適用されます。[技術一覧](https://docs.tablepro.app/security/privacy)にフィールド、接続先、設定を記載しています。ソースは[公開リポジトリ]({github})にあります。

## 概要 {#summary}

通常のクエリと結果は端末とデータベース間で送受信されます。利用データに SQL、行、認証情報は含まれません。Team Library への公開、サポートへの送信、AI や外部ツールとの共有を選んだ内容は、その受領者に届きます。

Mac と Linux の利用データは初期状態で有効で、無効にできます。公開済みの iPhone と iPad アプリは同意後にだけ送信します。直接送信する分析データはアカウントや購入と結び付きます。無効化してもアカウント通信やサーバー分析は止まりません。

サイトは閲覧を計測し、全ページで Crisp を読み込みます。Google Analytics Cookie は選択が必要です。ニュースレターは開封とクリックを計測します。アカウント削除後も PostHog、Crisp などに記録が残ります。[保存期間](#retention)と[権利](#rights)をご確認ください。[管理者](#controller)はアカウントのない方の請求も受け付けます。

## 管理者 {#controller}

{publisherCountry} の個人開発者 {publisherName} が、記載する個人データの管理者です。連絡先は [{email}](mailto:{email}) です。データ保護責任者はいません。チームのアカウント、招待、サービス記録は管理者として扱います。Team Library の公開内容はチームの指示に従って処理します。公開内容と閲覧者はチームが決めます。

## データと目的 {#data-use}

EEA と英国向けに各目的の法的根拠を示します。契約（第 6(1)(b) 条）、正当な利益（6(1)(f)）、同意（6(1)(a)）、法的義務（6(1)(c)）です。法的または同程度の重大な影響を持つ自動決定は行いません。

### アカウントと端末 {#account}

無料のローカル利用にアカウントは不要です。アカウントサービスにはメールアドレスが必要です。氏名、言語、ログイン方法、ライセンス、注文、端末、チームの役割と席を保存します。Mac/Linux の端末登録はマシン ID、端末名、プラットフォーム、アプリ/OS バージョンを送ります。端末名に氏名が入ることがあります。利用データとは別です。目的と根拠は契約に基づくアカウントとプランの提供です。

ログインにはメールのリンクとコード、パスキー、Apple、GitHub、Google を使います。パスキー記録は公開鍵、名前、同期状態、利用日を含みます。認証提供者は ID と確認済みメールを、Apple は氏名も提供する場合があります。Apple のトークンは暗号化し、連携解除や削除時に失効させます。変更は IP とユーザーエージェント付きで記録します。正当な利益は保護と不正調査です。

[ポータル]({account})でプロフィールや認証方法の変更、端末管理、JSON エクスポート、削除ができます。他のメンバーがいるチームの所有者は削除できません。削除は返金なしで購読を終了します。残る記録は[保存期間](#retention)に記載しています。

### 購入 {#purchases}

{merchant}（Polar Software, Inc.）は merchant of record かつ再販者です。独自の条件で氏名、メール、請求先、支払い情報を集め、支払い、税、領収書、紛争を処理します。完全なカード情報は受け取りません。

決済、税、通貨のため購入内容、言語、訪問元、IP を送ります。購入者/請求先情報、金額、注文/購読 ID、更新、解約、返金を受け取ります。注文にはメール、国、金額、流入元を保存します。未ログイン購入は必要に応じてメールの未確認アカウントを作ります。解約理由やコメントは {merchant} に届き購読に保存されます。処理は購入契約、税務/会計記録は法的義務に基づきます。必要情報がなければ決済できません。[{merchant} のポータル]({portal})、[利用条件](/ja/terms)、[返金](/ja/refund-policy)をご確認ください。

### チームと共有内容 {#library}

招待者はメール、役割、席の選択を提供します。所有者と管理者は氏名/メール、招待、チーム変更と招待先を見ますが、監査 IP やブラウザーは見ません。メンバーはチーム、プラン、席数、自分の役割を見ます。契約上のサービス提供に使用します。

Mac で Team Library に公開すると接続設定と保存クエリがサーバーに送られ、権限のあるメンバーに届きます。設定はホスト、ポート、DB、ユーザー、SSH/SSL、起動コマンド、Tunnel Command、AI 設定です。クエリは名前、SQL、キーワード、フォルダーです。パスワード欄は除外しますが、SQL や自由文中の秘密は除去しません。最終編集者を表示します。脱退だけでは共有内容を消しません。[削除時期](#retention)をご覧ください。Team Catalog は選んだ共有フォルダーに書き込みます。

### 利用とサービスの分析 {#analytics}

正当な利益は利用の理解、問題修正、購入計測です。Mac/Linux は[アプリ](#apps)のデータを送ります。サーバーもログイン、購入、端末、チームのイベントを PostHog に送ります。アカウント ID を含み、氏名/メールは含みません。ID がアプリとサービスの活動を結びます。スイッチはアプリのイベントだけを止め、必要な通信やサーバーイベントを止めません。[権利](#rights)で異議や削除を請求できます。

### ニュースレターとメール {#newsletter}

Amazon SES がコード、招待、通知、ニュースレターを送ります。サービスメールは依頼されたサービスを履行します。新規購読は確認と同意が必要です。アドレス、言語、登録/確認日、IP、ユーザーエージェント、登録ページ、同意文の版を保存します。

各ニュースレターは画像と `links.news.tablepro.app` で全受信者の開封/クリックを計測します。Amazon SES は時刻、リンク、IP、ユーザーエージェントを受け、集計用にサーバーへ渡します。画像遮断は開封計測を止めますがクリックは止めません。解除リンクとメールリンクは追跡しません。計測だけのスイッチはありません。本文かメールアプリのワンクリック機能で解除できます。その後の確認メールは送りません。再登録には確認が必要です。恒久的な不達と迷惑メール報告で送信を止めます。[連絡先](#controller)でアドレス削除を請求できます。

旧リストは確認済みかを問わず、未解除の全アドレスを移行しました。購入者、ライセンス所有者、ベータ登録者を含みます。解除済みは維持し、不達/苦情は送信停止リストへ移しました。[保存期間](#retention)をご覧ください。

### サポート {#support}

メッセージ、添付、診断は開発者と選んだサービスに届きます。あなたが含めた DB データや秘密も届きます。サイト/ポータルでチャットを読み込むと Crisp が IP、ブラウザー、閲覧ページを受けます。会話開始後は IP を保存します。ページ言語と、ログイン中はメール/アカウント ID を渡します。全ページの読み込みはサポート提供という正当な利益、開始した会話は同意に基づきます。

### 端末上のデータ {#local-data}

接続一覧、履歴、ローカルログ、タブは共有を選ばなければ端末に残ります。DB 通信は選んだサーバーへ行きます。パスワードはプラットフォームの認証情報ストアを使います。Mac は SSH 鍵を元の場所で参照します。分析にホスト名、ユーザー名、SQL、行、認証情報は含みません。[連携](#integrations)、Team Library、サポートには記載した例外があります。

### Mac {#mac-app}

直接分析とアカウント動作は 0.86.0、初版 0.86.0-beta.1 からです。ログインで端末登録とプラン取得を行います。トークンはその Mac の Keychain に残り iCloud Keychain に同期しません。既存ライセンスキーはログインに交換後、ローカルから削除します。

#### Mac 利用データ {#mac-usage-report}

初期状態で有効で、最初の送信前には尋ねません。**Settings > General > Privacy** の **Share usage data** を無効にしてください。無効で起動すると PostHog ライブラリは開始しません。自動クラッシュ報告はなく、PostHog の収集機能を無効にしています。

イベントは接続種別/数付きの毎日の利用、初回接続試行/成功、初めてクエリを実行した際の DB 種別、有料機能の制限と理由、アップグレードクリック、ログイン方法/ログアウト、ライセンス購入案内と回答です。PostHog は端末、画面、ネットワーク、セッション、アプリ、OS 情報を付加し、IP から概略位置を求めます。ログイン前はランダムなインストール ID で個人プロフィールなし。ログイン後はアカウント ID と版、アーキテクチャ、言語、位置のプロフィールです。ログアウトで新規 ID になります。[詳細](https://docs.tablepro.app/security/privacy#usage-data)をご覧ください。

#### 更新とプラグイン {#mac-updates}

更新フィードとカタログは updates.tablepro.app 経由で GitHub から取得します。ダウンロードや件数取得も GitHub へ行き、IP とユーザーエージェントを含みます。**Settings > General > Software Update** の **Automatically check for updates** を無効にすると自動確認を止めます。カタログは無効化できません。[技術詳細](https://docs.tablepro.app/security/privacy#update-checks)に旧版のフィードもあります。

#### 古い Mac 版 {#mac-license}

0.86.0 より前は同じ既定有効の設定でサーバーに報告します。マシン ID のハッシュ、版、接続種別/数、ライセンス状態、初回試行/成功日を含みます。更新設定も送りますがサーバーは捨てます。現在は Cloudflare の国を付け、IP/キーや個人プロフィールなしで PostHog へ転送します。ID でアカウント端末と関連付けられます。専用履歴は保存しませんが、ジョブ、ログ、バックアップ、旧アーカイブには残り得ます。[保存期間](#retention)をご覧ください。

旧版はキー入力後だけライセンスサービスに接続します。キー、ID、Mac 名、版を送ります。端末はアカウントに属し、有効化/解除は IP とユーザーエージェント付きで監査します。[一覧](https://docs.tablepro.app/security/privacy#older-mac-reports)にフィールドと間隔があります。

### iPhone と iPad {#ios-app}

公開アプリは初回または **Settings > Privacy** で **Share Usage Data** を有効にするまで利用報告を送りません。根拠は同意です。毎日サーバーから IP を除き、Cloudflare の国付き、個人プロフィールなしで PostHog に送ります。Apple 端末 ID のハッシュ、プラットフォーム、版、アーキテクチャ、言語、接続種別/数、初回試行/成功、初めてクエリを実行した日を含みます。常にライセンスなしを報告し更新設定はありません。アカウント、ライセンス、更新、プラグイン確認もしません。

DB/SSH、任意の iCloud、SQL Server 用 Microsoft Entra ログインは各サービスに送ります。パスワード/貼り付けた SSH 鍵は Keychain、証明書/履歴は端末に保存します。接続はローカル Spotlight に入ります。Live Activity は Hide Query を有効にしないとロック画面に SQL を表示し得ます。別途 Apple の Share With App Developers 設定で App Store Connect 経由のクラッシュ/利用統計を受け取る場合があります。アプリにクラッシュ収集や外部分析ライブラリはありません。[iOS 詳細](https://docs.tablepro.app/ios#privacy)をご覧ください。

### Linux {#linux-app}

0.1.0-beta.1 からログインで[アカウント](#account)の端末登録を行います。秘密はデスクトップのキーリングを使います。パッケージ更新は選んだ配布者に従います。自動クラッシュ報告はありません。

#### Linux 利用データ {#linux-usage-data}

0.1.0-beta.1 から初期状態で有効です。Preferences > General > Privacy の Share usage data で無効にします。PostHog EU に直接、接続種別/数付き毎日の利用、初回試行/成功/クエリの種別、ログイン/アウト、アップグレード、ライセンス案内/Buy 回答を送ります。ID、版、アーキテクチャ、言語、SDK 情報を含みます。IP から概略位置を求めます。ログイン前はランダム ID でプロフィールなし、後はアカウントプロフィールで利用と購入を結びます。ログアウトで ID をリセットします。ホスト名、SQL、行、認証情報は含みません。別の端末登録にはホスト名が入ります。

無効化は新しい送信を止めます。進行中の要求は完了する場合があります。過去のイベント削除やアカウント/サーバー分析停止にはなりません。[保存期間](#retention)、[権利](#rights)、[技術一覧](https://docs.tablepro.app/security/privacy#linux-usage-data)をご覧ください。

## 選択するサービス {#integrations}

DB、SSH、プロキシ提供者は要求した通信を直接受けます。設定した認証サービスは認証要求を受けます。Apple Maps は地図、DuckDB はクエリ用拡張を提供します。接続/AI ヘルパーは各提供者へ通信します。各サービスの条件が適用されます。

### iCloud と Handoff {#icloud}

任意の iCloud Sync は接続、グループ、タグ、設定、保存クエリ、SSH プロファイルを私用 CloudKit に保存します。 Mac では、テーブルやデータベースのお気に入りとフォルダー、認証情報プロファイルの名前、ユーザー名、パスワードモードも同期します。プロファイルのパスワードは同期しません。Apple がホストし、開発者は読めません。パスワード同期は別設定で既定無効、エンドツーエンド暗号化した iCloud Keychain を使います。Mac では AI 鍵や旧ライセンスキーなど同じストアの秘密も対象です。アカウントトークンは同期しません。Mac は Pro/Team が必要、iOS は無料です。Handoff は端末間で接続 ID と表名、表なしなら接続名/ホストを渡します。認証情報は渡しません。[設定](https://docs.tablepro.app/features/icloud-sync)をご覧ください。

### AI と外部ツール {#ai-tools}

AI は選んだ提供者かローカルモデルへ直接送ります。プロンプト、スキーマ、SQL、会話を含み得ます。グリッド行添付は既定無効です。許可したクエリツールの結果も会話に入り、添付設定とは無関係に提供者へ届きます。GitHub Copilot は npm からヘルパーを取得し、Send telemetry to GitHub は初期状態で有効です。

MCP は既定無効で、その間はブリッジやペアリングでも起動できません。有効時は認証済みクライアントが権限内でデータを求めます。AI クライアントは結果を自サービスに送る場合があります。外部 MCP サーバーは承認した引数を受けます。[AI/MCP 設定](https://docs.tablepro.app/security/privacy#ai-providers)をご覧ください。

## サイトとブラウザー保存 {#website}

サーバーと Cloudflare は IP、ユーザーエージェント、ページを受けます。Cloudflare Web Analytics は閲覧、参照元、読込時間、ブラウザー/OS/端末分類、国を数え、保存や指紋採取はしません。正当な利益は利用把握と維持です。

Google Analytics は Consent Mode です。Allow 前は Cookie/保存 ID なしのページ信号を送ります。同意で Cookie、訪問、ダウンロード、購入計測を有効にします。広告保存、個人化、広告ユーザーデータは常に拒否します。Google は GA4 が IP を保存しないと説明しています。

Crisp は[サポート](#support)のとおり全ページで読み込みます。Buy にポインター/Tab を合わせると jsDelivr から {merchant} スクリプトを読み、IP/ブラウザーを渡します。クリックで決済を開きます。フォーム開始時の Turnstile は不正防止の正当な利益です。国/時差は言語/地域割引の提案に正当な利益で使います。要求に Cookie はなく、回答はページに残しません。

初回訪問で `tablepro:attribution` を 90 日保存します。タグ/参照元、入口ページ、日付です。決済で訪問元を {merchant} にメタデータとして渡し、注文に残し、決済/支払いと PostHog に送ります。ページ/日付は残しません。根拠は購入元計測の正当な利益です。公開の購読、決済、割引要求は認証情報を省き、ポータル Cookie を設定しません。ポータルに分析スクリプトはありませんがサーバーイベントはあります。

### ドキュメント {#docs}

Mintlify が docs.tablepro.app をホストします。ページ、Google Fonts、GitHub スター数の要求で各提供者に IP/ブラウザーが届きます。Docs は別途同意を聞きます。Allow 前は分析 Cookie/訪問者 ID を保存しません。Allow で Google Analytics と Mintlify ID を有効にします。フッターの Cookie settings で撤回し削除できます。サイトの選択はこのオリジンに引き継ぎません。

### Cookie と保存 {#cookies}

Cloudflare Web Analytics はブラウザーに保存しません。公開ページに独自 Cookie はありません。以下の期間は提供者の保存期間とは別です。必要保存はログインや選択を維持します。同意/正当な利益の目的は以下のとおりです。

| 名前/サービス | 目的と開始 | 期間と操作 |
| --- | --- | --- |
| `_ga`, `_ga_<ID>` | 同意後の Google Analytics | 最長 2 年、拒否で削除 |
| `tablepro:analytics-consent` | 必要な選択記録、サイト/Docs 別 | 消去まで |
| `tablepro:attribution` | 決済時の初回流入元、正当な利益 | 90 日 |
| `theme`, `tablepro:language`, `tablepro:campaign-closed`, `tablepro:linux-install` | 外観、言語選択/却下、閉じたセール、選んだ Linux インストール方法、正当な利益 | 消去まで、ポータルテーマは別 |
| `mintlify_anonymous_id` | Docs 同意後の ID | 消去または拒否まで |
| `crisp-client/` Cookie | 各ページ読込後のチャット継続、正当な利益 | 6 か月、再訪で更新 |
| `__Host-tp_session` | 必要なポータル認証 | ログイン後 30 日、処理中最大 10 分、ログアウトで削除 |
| `locale`, `context`, `sign-in-return-to` | 言語、Personal/チーム表示、戻り先、正当な利益 | 前二つは消去まで、戻り先 15 分 |

## 処理場所 {#transfers}

OVH と Amazon SES はシンガポール（SES は `ap-southeast-1`）、PostHog は EU、Crisp はフランスに拠点があります。{publisherName} はベトナムから運営します。{merchant}、Google、GitHub、Cloudflare、Amazon Web Services、Mintlify などの米国提供者は米国で処理します。保存/バックアップは他国に及ぶ場合があります。EEA/英国の必要な保護は各提供者の標準契約条項など承認済みの仕組みに依拠し、Google は EU-US Data Privacy Framework も使います。[連絡先](#controller)で詳細を請求できます。

## 選択と権利 {#rights}

アプリ設定、サイト/Docs の Cookie settings、メール解除を使ってください。同意撤回は将来に適用され、過去の処理を無効にしません。設定は古いデータやサーバー分析を消しません。[ポータル Settings]({account})でエクスポート/削除できますが、全記録をカバーしません。

居住地に応じてアクセス、訂正、削除、制限、移転、正当な利益への異議を請求できます。アカウント不要で[連絡先](#controller)へメールしてください。記録特定のためインストール ID などを求める場合があります。ライセンスキーを平文メールで送らないでください。1 か月以内に回答します。データ保護当局へ苦情を申し立てられます。法的保存義務で削除が制限される場合があります。

### 地域別の権利 {#regional-rights}

**カリフォルニア州の居住者**。California Consumer Privacy Act により、収集する個人情報を知る権利、削除を求める権利、販売を拒否する権利、およびこれらの権利の行使により異なる扱いを受けない権利があります。運営者は個人情報を販売しません。

## 子ども {#children}

TablePro は 16 歳未満を対象とせず、知りながらその個人情報を集めません。子どもがデータを渡したと思われる場合は連絡してください。削除します。

## 安全性 {#security}

サービス通信は HTTPS です。アカウントにパスワードはありません。認証情報とチーム API トークンはハッシュ保存で、[保存期間](#retention)の一時メールジョブは例外です。システムへのアクセスは {publisherName} と[受領者](#sharing)に限定します。完全に安全なシステムはありません。[安全性ページ](/ja/security#report)で脆弱性を報告してください。
