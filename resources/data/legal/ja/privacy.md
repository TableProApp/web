このポリシーは、Mac 版 TablePro、iPhone・iPad 版 TablePro、tablepro.app のウェブサイト、docs.tablepro.app のドキュメント、tablepro.app/account のアカウントポータルに適用されます。それぞれが現在実際に送信・保存している情報を説明します。両アプリは AGPLv3 のオープンソースで、以下のデータを送信するコードは [TablePro のリポジトリ]({github})で確認できます。

## 概要 {#summary}

- Mac アプリは 1 日 1 回、利用状況レポートを TablePro に送信します。初期設定でオンですが、オフにできます。iPhone・iPad アプリは、お客様がオンにした場合のみ送信します。
- ライセンスを有効化すると、Mac アプリは {revalidateDays} 日ごとに運営者のサーバーで確認します。確認には Mac の名前も含まれます。
- 実行したクエリ、結果、パスワードは TablePro に送信されません。例外は、お客様が Team Library に公開する接続設定（パスワードは含まれません）と保存済みクエリです。
- AI リクエストは Mac アプリから設定した AI プロバイダーへ直接送られ、運営者には送られません。
- 運営者のサーバーは、すべての利用状況レポートとライセンス確認の IP アドレスを保存し、各レポートの国を調べます。この記録の保存期間に上限は設定していません。
- ウェブサイトは Cookie を設定しない Cloudflare Web Analytics でページ閲覧数を集計します。Google Analytics も読み込みますが、Cookie はお客様が許可した場合にのみ設定します。すべてのページでチャットサービス Crisp も読み込み、Crisp 独自の Cookie を設定します。
- 購入商品の販売者は、運営者の merchant of record である {merchant} です。

## 責任者 {#controller}

TablePro のアプリとこのウェブサイトを公開している、{publisherCountry}・{publisherCity}の個人開発者 {publisherName}（以下「運営者」）が、ここに記載する個人データの責任者（データ管理者）です。このポリシーやお客様のデータについてのご質問は、[{email}](mailto:{email}) にお送りください。

## Mac 版 TablePro {#mac-app}

### 利用状況レポート {#mac-usage-report}

Mac アプリは起動の約 10 秒後、その後は動作中に 1 日 1 回、`api.tablepro.app` へ利用状況レポートを送信します。**初期設定でオンになっており、初回送信の前に確認はしません**。オフにするには、**Settings > General > Privacy** を開き、**Share anonymous usage data** のチェックを外してください。

レポートには次の情報が含まれます。

- マシン ID：Mac のハードウェア UUID の SHA-256 ハッシュ（UUID 自体は送信しません）。
- プラットフォーム、アプリのバージョン、macOS のバージョン、プロセッサアーキテクチャ、アプリの言語。
- 開いている接続のデータベースの種類の名前（例：PostgreSQL）と、開いている接続の数。
- ライセンスが有効化されているかどうか。
- 初めて接続を試みた日時と、初めて接続に成功した日時。
- アップデート設定（インストール方法と確認頻度）。この情報はレポートの到着時に運営者のサーバーが破棄します。

ホスト名、ユーザー名、パスワード、クエリ、行データは含まれません。

運営者のサーバーは、各レポートを送信元の IP アドレスとともに保存します。その IP アドレスを ip-api.com へ送り、国を調べます。失敗した場合は ipinfo.io、続いて geoplugin.net を使用します。この問い合わせは暗号化されていない HTTP で行われます。国はレポートとともに保存します。以下のライセンス確認では同じマシン ID を送信するため、ライセンスを有効化した Mac のレポートは、そのライセンスと関連付けられます。

### ライセンス確認 {#mac-license}

Mac アプリがライセンスサーバーに通信するのは、ライセンスキーの入力後のみです。有効化時、前回の確認から {revalidateDays} 日以上経過した後の起動時、およびその後 {revalidateDays} 日ごとに通信します。各確認では次の情報を送信します。

- ライセンスキー。
- 上記のマシン ID。
- macOS で設定された Mac の名前（お客様の名前が含まれることがあります）。
- アプリと macOS のバージョン。

Mac の有効化を解除する際に送るのは、ライセンスキーとマシン ID のみです。

運営者のサーバーはすべてのライセンスリクエストの IP アドレスと内容を記録し、有効化した各 Mac のマシン ID と名前をライセンスに紐付けて保存します。アカウントポータルには Mac の名前が表示されます。サーバーに接続できない場合、有料機能は最後に確認が成功してから {graceDays} 日間使えます。

### Team Library {#library}

Team Library は Team ライセンスの機能です。接続で **Share > Publish to Team Library…** を選ぶか、Favorites サイドバーで **Publish Saved Queries to Team…** を選ぶと、Mac アプリは公開する情報を運営者のサーバーへアップロードします。

- 接続設定：ホスト、ポート、データベース名、ユーザー名、SSH と SSL の設定、ドライバーオプション、起動時コマンド、Tunnel Command の設定、Safe Mode レベル、AI 設定。パスワードは含みません。
- 保存済みクエリ：名前、SQL テキスト、キーワード、フォルダー。

同じ Team ライセンスの Mac は起動時に、最大でも週に 1 回ライブラリをダウンロードします。公開した Mac は、その直後に再度ダウンロードします。再公開すると、以前に公開した内容を置き換えます。チームメンバーを削除すると、そのメンバーが公開したすべての内容が削除されます。ライセンスが失効または停止された場合も、お客様が削除を依頼するまでライブラリは運営者のサーバーに残ります。

もう一つの Team 機能である Team Catalog は、選択した共有フォルダーにパスワードを含まない接続ファイルを書き込みます。運営者のサーバーを経由しません。

### アップデートとプラグイン {#mac-updates}

- **アップデート確認**。Mac アプリは 1 日 1 回、GitHub（`raw.githubusercontent.com`）から更新フィードをダウンロードします。すべてのウェブリクエストに含まれる IP アドレスと、アプリのバージョンを含む User-Agent 以外に、Mac の情報は送信しません。オフにするには **Settings > General > Software Update** を開き、**Automatically check for updates** のチェックを外します。アップデート自体も GitHub からダウンロードします。
- **プラグインカタログ**。起動時とプラグイン設定を開いたときに、利用可能なドライバーとテーマの一覧を GitHub からダウンロードします。これをオフにする設定はありません。インストールするドライバーとテーマも GitHub からダウンロードし、プラグインブラウザーは GitHub API からダウンロード数を取得します。

これらのリクエストでは GitHub に IP アドレスが送られ、GitHub 独自のプライバシー声明が適用されます。

### お客様が選んで利用するサービス {#mac-third-parties}

Mac アプリは、お客様が設定した場合にのみ次のサービスへ直接データを送信します。TablePro は経由しません。

- **お客様のデータベース、SSH サーバー、プロキシ**は、接続が送信する情報を受け取ります。
- **AI プロバイダー**。プロバイダーを追加し、AI アシスタントまたはインライン提案を使うと、リクエストはそのプロバイダー、または Mac 上で動作するモデルへ送られます。初期設定では、データベースの種類と名前、スキーマのテーブルとカラム定義、現在のクエリが含まれます。結果の行データは、お客様がオンにした場合のみ送られます。プロバイダー自身の規約が適用されます。GitHub Copilot を追加すると、言語サーバーが npm からダウンロードされ、「Send telemetry to GitHub」は初期設定でオンです。
- **ログインサービス**：接続で利用する Microsoft Entra ID、Google、Amazon Web Services、Cloudflare Access。
- **Apple Maps**は、結果を地図に表示する際に地図タイルを提供します。
- **DuckDB**は、クエリで拡張機能を初めて使うときに、その拡張機能を提供します。
- **MCP クライアント**。MCP サーバーは初期設定ではオフです。お客様がオンにするか、設定済みの MCP クライアントが TablePro のブリッジを起動またはペアリングすると開始し、Mac 内（127.0.0.1）のみで待ち受けます。Claude や Cursor などの接続した AI クライアントは、要求した結果を受け取り、独自の規約に従って自社サービスへ送信します。
- **追加した MCP サーバー**。AI セッションは、お客様が承認したツール呼び出しとその引数を、そのサーバーへ送信します。

### Mac 内に残るデータ {#mac-local}

パスワードは macOS キーチェーンに保存されます。接続一覧、クエリ履歴、Query Insights、Data Rewind のスナップショット、設定、開いているタブは Mac に保存されます。SSH キーはディスク上の場所を参照し、コピーはしません。アプリにクラッシュレポーターや他社のアクセス解析ライブラリは含まれていません。

## iPhone・iPad 版 TablePro {#ios-app}

初回起動時または **Settings > Privacy** で、**Share Usage Data をオンにしない限り、TablePro へは何も送信されません**。オンにすると、Mac アプリと同じサーバーへ 1 日 1 回レポートを送ります。サーバーは同じ方法で IP アドレスを保存し、国を調べます。レポートには、Apple がデバイス上のアプリに付与する識別子の SHA-256 ハッシュ、プラットフォーム、アプリと iOS のバージョン、プロセッサアーキテクチャ、アプリの言語、開いている接続のデータベースの種類の名前、開いている接続の数、初めて接続を試みた日時、初めて接続に成功した日時、初めてクエリを実行した日時が含まれます。アップデート設定は含まれず、ライセンスは常に「有効化されていない」と報告されます。アプリにはどちらも存在しないためです。

ライセンス確認、アップデート確認、プラグインリクエストは行いません。任意のレポートを除き、接続先はお客様のデータベースと SSH サーバー、iCloud Sync をオンにした場合の Apple の iCloud、SQL Server 接続で Microsoft Entra ID を使う場合の Microsoft のみです。

デバイス上では、パスワードと貼り付けた SSH キーをキーチェーンに保管し、証明書は同期しません。クエリ履歴はデバイス内に残ります。接続はデバイス上の Spotlight インデックスに登録され、検索できます。クエリ実行中は、**Settings > Live Activities > Hide Query** をオンにしない限り、ライブアクティビティがロック画面と展開した Dynamic Island に SQL を表示します。

iPhone または iPad の設定でアプリ開発者と解析情報を共有すると、Apple がクラッシュレポートや利用統計を App Store Connect 経由で運営者へ提供する場合があります。アプリ自体にクラッシュレポーターや他社のアクセス解析ライブラリはありません。

## iCloud Sync と Handoff {#icloud}

iCloud Sync は、Mac と iPhone・iPad のいずれでも、お客様がオンにするまで無効です。オンにすると、記録はお客様の iCloud アカウント内の非公開データベース（コンテナ `iCloud.com.TablePro`）へ保存されます。TablePro は読むことができません。

- Mac では同期対象を選べます。接続、グループ、タグ、設定、SSH プロファイル、認証情報プロファイル（名前とユーザー名のみで、パスワードは含みません）、テーブルとデータベースのお気に入り、保存済みクエリ（SQL テキストを含む）、テーブルフォルダーです。接続の記録にはホスト、ポート、ユーザー名、データベース名、SSH と SSL の設定、起動時コマンド、接続前スクリプト、AI ルールが含まれます。クエリ履歴、Data Rewind のスナップショット、パスワードの取得元は同期しません。
- iPhone・iPad は接続、グループ、タグを同期します。
- パスワードを同期するには、Mac の Sync Categories の **Passwords**、または iPhone・iPad の **Sync Passwords** もオンにする必要があります。iCloud キーチェーンを利用します。Mac では、AI プロバイダーのキーやライセンスキーなど、TablePro がキーチェーンに保存するその他の秘密情報も同期します。

Mac の iCloud Sync は Starter または Team ライセンスの機能です。iPhone・iPad では無料です。

Handoff は Apple を通じて、お客様自身のデバイス間で、開いている接続の ID とテーブル名を渡します。テーブルを開いていない場合は接続名を、名前がない場合はホストを渡します。設定や認証情報は送信しません。

## ウェブサイト {#website}

**ホスティング**。ウェブサイトとアカウントポータルは Cloudflare の背後にある運営者のサーバーで動作します。一般的なウェブサーバーと同様、IP アドレス、ブラウザーの User-Agent、要求した各ページのアドレスを受け取ります。

**Cloudflare Web Analytics**。Cloudflare はウェブサイトとアカウントポータルのページに Web Analytics スクリプトを追加します。ブラウザーは `static.cloudflareinsights.com` から読み込み、ページ、リンク元サイト、読み込み時間、ブラウザー、OS、デバイスの種類をページ閲覧ごとに Cloudflare へ報告します。Cloudflare は接続元の国も追加します。スクリプトは Cookie を設定せず、ブラウザーにも何も保存しません。Cloudflare は、IP アドレスやブラウザーの情報をフィンガープリントによる識別に使わないとしています。運営者に提供されるのは、ページ別・国別の閲覧数などの集計値で、訪問者個別の記録ではありません。法的根拠：正当な利益。

**Google Analytics**。サイトはすべてのページで Consent Mode の Google Analytics を読み込みます。Cookie の質問で**許可**を選ぶまでは Cookie を設定せず、デバイスに識別子を保存することなく、ページごとに Cookie を使わないシグナルのみを Google に送ります。許可すると `_ga` と `_ga_<ID>` Cookie を設定し、閲覧ページ、ダウンロードのクリック、チェックアウトの開始などを計測します。広告用ストレージ、広告のパーソナライズ、広告用ユーザーデータは常に拒否します。Google は Google Analytics 4 が IP アドレスを記録・保存しないとしています。運営者のプロパティは Google の初期設定の保存期間を使用し、Google は収集したユーザー単位・イベント単位のデータを 2 か月後に削除します。識別子ではなく集計値を保持する標準レポートは影響を受けません。法的根拠：Cookie へのお客様の同意。

**チャット**。ウェブサイトとアカウントポータルのすべてのページに、チャットプロバイダー Crisp のボタンを表示します。ページの読み込み後、ブラウザーは `client.crisp.chat` からスクリプトを読み込み、Crisp は [Cookie とブラウザーストレージ](#cookies)に記載する Cookie を設定します。Crisp は IP アドレス、ブラウザーの情報、閲覧ページのアドレス、入力したメッセージを受け取り、会話を始めた場合は IP アドレスを保持します。運営者はページの言語のみを Crisp に伝え、お客様に関するその他の情報は伝えません。Crisp の所在地はフランスです。

**チェックアウトスクリプト**。購入ボタンにポインタを合わせるか Tab キーでフォーカスすると、ブラウザーは jsDelivr（`cdn.jsdelivr.net`）から {merchant} のスクリプトを読み込みます。jsDelivr は IP アドレスとブラウザーの情報を受け取ります。{merchant} のチェックアウト自体が開くのはクリックしたときだけです。

**購入の流入元**。サイトに到着すると、ブラウザーは初回訪問の記録を `tablepro:attribution` としてローカルストレージに 90 日間保存します。記録は訪問元（アクセスしたリンクの `ref`・`utm_*` タグ、またはリンク元サイト）、最初に開いたページ、日時です。購入を開始するとチェックアウトリクエストとともに送られますが、運営者のサーバーは破棄します。検証、読み取り、保存はせず、{merchant} にも渡しません。

**ドキュメント**。docs.tablepro.app のドキュメントは Mintlify がホストしています。Mintlify はページごとにお客様の IP アドレスとブラウザーの情報を受け取り、ページは Google Fonts からフォントを読み込みます。ドキュメントは、このサイトでの回答を読み取れないため、独自に Cookie の質問を表示します。そこで **Allow** を選ぶまでは Cookie を設定せず、訪問者 ID も保存しません。許可すると、Google Analytics が `_ga` と `_ga_<ID>` Cookie を設定してドキュメントの閲覧を計測し、Mintlify は集計のためにランダムな訪問者 ID `mintlify_anonymous_id` をローカルストレージに保存します。ドキュメントのフッターにある **Cookie settings** で回答を変更でき、拒否すると両方が削除されます。法的根拠：お客様の同意。

**言語と地域割引**。ブラウザーの言語にサイトの対応言語が含まれない場合にページを適切な言語で提案するため、またチェックアウトで適用される地域割引を表示するため、サイトは Cloudflare（`/cdn-cgi/trace`）と運営者のサーバーに接続元の国を問い合わせ、デバイスのタイムゾーンを読み取ることがあります。どちらのリクエストにも Cookie は含まれず、ページは応答の内容を保存しません。法的根拠：正当な利益。

サイトの閲覧では、サイト独自の Cookie は設定されません。公開サイトからのニュースレター登録、チェックアウト、割引コード確認のリクエストは認証情報を含めないため、アカウントポータルの Cookie を送信せず、応答の Cookie も受け入れません。アカウントポータルのページを開く操作は別で、以下のポータル Cookie が設定されます。サイトがブラウザーに保持する情報はすべて [Cookie とブラウザーストレージ](#cookies)に掲載しています。

## 購入 {#purchases}

ライセンスは merchant of record 兼再販業者の {merchant}（Polar Software, Inc.）が販売します。お客様は {merchant} 独自の購入者向け規約とプライバシーポリシーに基づいて購入します。{merchant} は支払いを受け取り、売上税や VAT の計算・納付、領収書と請求書の送付、決済問題と紛争への対応を行います。名前、メールアドレス、請求先住所、支払い情報を収集します。運営者がお客様のカード情報の全体を見ることはありません。

運営者は {merchant} から、メールアドレス、入力された名前と請求先住所、購入内容、金額、注文・サブスクリプション ID、その後の更新・解約・返金などの変更を受け取ります。メールをその言語で届けるため、運営者は購入したページの言語を {merchant} に伝えます。請求書、領収書、支払い方法、サブスクリプションは [{merchant} のカスタマーポータル]({portal})で管理でき、購入時のメールアドレスでログインします。返金は[返金ポリシー](/ja/refund-policy)、ライセンスの利用範囲は[利用規約](/ja/terms)をご覧ください。

## アカウントポータル {#account}

tablepro.app/account の[アカウントポータル](/account?locale=ja)は、ライセンス購入者向けです。購入時のメールアドレスへ送るリンクでログインします。リンクは一度だけ使え、15 分で失効します。ライセンス、有効化した Mac（名前で表示）、Team ライセンスの場合はメンバー、招待、シート、Team Library を表示します。

運営者はライセンスと注文にメールアドレスを紐付けて保存し、お客様が使用する言語も保存して、その言語でメールを送ります。チームに誰かを招待する場合、その人のメールアドレスと役割を保存し、招待コードをメールで送ります。

## ニュースレター {#newsletter}

リリースノートを購読すると、メールアドレスと登録したページの言語を保存します。まず確認リンクをメールで送り、すべてのニュースレターに配信停止リンクを付けます。配信停止後はニュースレターを送りません。メールアドレス自体の削除も希望する場合は、ご連絡ください。

## Cookie とブラウザーストレージ {#cookies}

公開サイトの閲覧では、サイト独自の Cookie は設定しません。ニュースレター登録、チェックアウト、割引コード確認のリクエストは認証情報を含めず、ポータル Cookie を設定しません。アカウントポータルのページを開くと、以下の厳密に必要な 2 つの Cookie が設定されます。Cloudflare Web Analytics は Cookie を設定せず、ブラウザーにも何も保存しません。Google Analytics の Cookie は許可するまで設定されません。Crisp はチャットの読み込み後、すべてのページで Cookie を設定します。ここに記載する情報は広告に利用されず、販売もされません。

- **`_ga` と `_ga_<ID>`**（Google Analytics の Cookie、最長 2 年、解析を許可した場合のみ）：ブラウザーのランダムな識別子と現在の訪問状態です。拒否した場合や後から回答を変更した場合は削除します。法的根拠：同意。
- **`tablepro:analytics-consent`**（ローカルストレージ、消去するまで）：解析の質問への回答を保存し、ページごとに質問しないようにします。ウェブサイトとアカウントポータルで共有します。法的根拠：お客様の選択を尊重するために厳密に必要。
- **`tablepro:attribution`**（ローカルストレージ、90 日）：[ウェブサイト](#website)で説明した初回訪問の記録です。お客様の識別子は含まず、チェックアウトリクエストとともにのみ送られ、サーバーで破棄されます。法的根拠：正当な利益。
- **`theme`** と **`tablepro:banner-dismissed`**（ローカルストレージ、消去するまで）：ライト、ダーク、システムの表示設定と、閉じたバナーおよび非表示の期限を保存します。期限は 30 日、ライセンスを持っていると申告した場合や購入した場合は 1 年です。法的根拠：正当な利益。
- **`tablepro:language`**（ローカルストレージ、消去するまで）：言語メニューまたは言語バーで選んだ言語と、提案を閉じた言語を保存し、同じ言語を再び提案しないようにします。法的根拠：正当な利益。
- **`mintlify_anonymous_id`**（docs.tablepro.app のローカルストレージ、Mintlify が設定、そこで Google Analytics を許可した場合のみ）：[ウェブサイト](#website)で説明した訪問者 ID です。拒否すると削除されます。ドキュメントは独自の `tablepro:analytics-consent` の回答を保存します。法的根拠：同意。
- **`crisp-client/` で始まる Cookie**（Crisp、例：`crisp-client/session/…`、6 か月、再訪時に更新、チャット読み込み後はすべてのページで設定）：ページや訪問をまたいでチャットと会話を維持します。法的根拠：すべてのページでサポートを提供するための正当な利益。
- **`tablepro-session` と `XSRF-TOKEN`**（アカウントポータルの Cookie、2 時間）：ログイン状態を維持し、ポータルのフォームをクロスサイトリクエストフォージェリから保護します。購入確認やニュースレターのページなど、ポータルの他のページを開いたときにも設定されます。公開サイトからのニュースレター登録、チェックアウト、割引コード確認のリクエストは認証情報を含めず、これらの Cookie を保持しません。法的根拠：厳密に必要。

## 法的根拠 {#lawful-basis}

欧州経済領域と英国の利用者に対する GDPR および UK GDPR に基づく法的根拠は次のとおりです。

- **契約**（第 6 条第 1 項（b））：ライセンスの販売・提供、ライセンス確認、アカウントポータル、Team Library。
- **正当な利益**（第 6 条第 1 項（f））：Mac アプリの利用状況レポートと国の照会、ライセンスリクエストの記録、セキュリティと不正利用防止、ウェブサーバーログ、Cloudflare Web Analytics、購入の流入元記録、言語と地域割引のための国の照会、すべてのページのチャット。
- **同意**（第 6 条第 1 項（a））：Google Analytics の Cookie、iPhone・iPad アプリの利用状況レポート、ニュースレター、お客様が開始するチャットの会話。
- **法的義務**（第 6 条第 1 項（c））：税務・会計記録、適法な要請への回答。

- **{merchant}**：購入の merchant of record。

## 国際移転 {#transfers}

上記のサービスは複数の国で運営されており、お客様のデータが居住国外で処理される場合があります。{merchant}、Google、GitHub、Cloudflare、Mintlify は米国でデータを処理します。Google は EU-US Data Privacy Framework と標準契約条項に基づいて処理します。法律で必要な場合、EEA と英国からの移転は標準契約条項またはその他の承認された仕組みに基づきます。

## データの保存期間 {#retention}

- **利用状況レポート**と IP アドレス・国：保存期間の上限は設定しておらず、自動削除もしません。
- **ライセンス記録**：有効化した Mac の ID と名前、ライセンスリクエストとその IP アドレスの記録は、ライセンスが存在する間保存します。自動削除はありません。
- **注文**：税務・会計のため保存します。
- **Team Library**：再公開、公開したメンバーの削除、またはお客様からの削除依頼まで保存します。ライセンス終了後も残ります。
- **アカウントのログインリンク**：15 分で失効し、その後削除します。ポータルのセッションは 2 時間です。
- **ニュースレター**：配信停止、またはお客様の依頼によるアドレス削除まで。
- **Google Analytics**：ユーザー単位・イベント単位のデータは 2 か月。運営者のプロパティが使用する Google の初期設定の期間です。Cookie は最長 2 年保持され、拒否した場合は削除されます。
- **Cloudflare Web Analytics**：運営者には直近 6 か月のページ閲覧の集計値を表示します。ブラウザーには何も保存しません。
- **チャットとサポートメール**：削除するまで Crisp と運営者のメールボックスに保存します。会話やメールの削除をご希望の場合はご連絡ください。
- **ウェブサーバーログ**：セキュリティと問題解決のため保存します。固定の期間はまだ設定していません。
