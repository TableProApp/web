このポリシーは、Mac 版 TablePro、iPhone・iPad 版 TablePro、tablepro.app のウェブサイト、docs.tablepro.app のドキュメント、account.tablepro.app のアカウントポータルに適用されます。それぞれが現在実際に送信・保存している情報を説明します。両アプリは AGPLv3 のオープンソースで、以下のデータを送信するコードは [TablePro のリポジトリ]({github})で確認できます。

## 概要 {#summary}

- Mac アプリは利用状況データを送信します。初期設定でオンですが、オフにできます。iPhone・iPad アプリは、お客様がオンにした場合のみ利用状況レポートを送信します。
- TablePro アカウントにサインインするかライセンスキーを有効化すると、Mac アプリは Mac を名前とともに運営者のサーバーに登録し、定期的にプランを確認します。
- 実行したクエリ、結果、パスワードは TablePro に送信されません。例外は、お客様が Team Library に公開する接続設定（パスワードは含まれません）と保存済みクエリです。
- AI リクエストは Mac アプリから設定した AI プロバイダーへ直接送られ、運営者には送られません。
- TablePro アカウントに対応したバージョン以降、Mac アプリは利用状況データを EU にある製品分析サービス PostHog へ直接送ります。PostHog は Mac の IP アドレスを受け取り、そこからおおよその位置を割り出します。それ以前のバージョンと iPhone・iPad アプリは利用状況レポートを運営者のサーバーへ送り、サーバーは IP アドレスなしで PostHog に転送します。アカウントには、サインインや新しいデバイスなど、アカウントへの変更の記録が、各変更を行ったリクエストの IP アドレスとブラウザーとともに残ります。
- ウェブサイトは Cookie を設定しない Cloudflare Web Analytics でページ閲覧数を集計します。Google Analytics も読み込みますが、Cookie はお客様が許可した場合にのみ設定します。すべてのページでチャットサービス Crisp も読み込み、Crisp 独自の Cookie を設定します。
- account.tablepro.app のアカウントポータルは解析スクリプトを読み込みません。サインイン状態を保つ Cookie を 1 つ設定し、設定画面ではアカウントのデータのダウンロードやアカウントの削除ができます。
- 購入商品の販売者は、運営者の merchant of record である {merchant} です。

## 責任者 {#controller}

TablePro のアプリとこのウェブサイトを公開している、{publisherCountry}・{publisherCity}の個人開発者 {publisherName}（以下「運営者」）が、ここに記載する個人データの責任者（データ管理者）です。このポリシーやお客様のデータについてのご質問は、[{email}](mailto:{email}) にお送りください。

## Mac 版 TablePro {#mac-app}

### 利用状況データ {#mac-usage-report}

TablePro アカウントに対応したバージョン以降、Mac アプリは利用状況データを、EU にある製品分析サービス PostHog（`eu.i.posthog.com`）へ直接送ります。**初期設定でオンになっており、最初のイベントを送る前に確認はしません**。オフにするには、**Settings > General > Privacy** を開き、**Share usage data** のチェックを外してください。オフの間、アプリは PostHog に何も送りません。設定がオフのまま起動した場合は、PostHog のライブラリ自体を起動しません。

アプリは次のときにイベントを送ります。

- 動作中に 1 日 1 回。開いている接続のデータベースの種類の名前（例：PostgreSQL）と、開いている接続の数を付けます。
- 初めて接続を試みたとき、初めて接続に成功したとき、初めてクエリを実行したとき。それぞれデータベースの種類を付けます。
- 有料機能が使えないことを表示したとき。アプリの起動ごとに機能 1 つにつき 1 回、機能と理由（サインインしていないなど）を付けます。
- アップグレードをクリックしたとき。クリックしたアプリ内の場所を付けます。
- サインインしたとき（アプリ内、ライセンスキー、または Mac に保存済みのキーの交換という方法を付けます）と、サインアウトしたとき。

PostHog のライブラリは、すべてのイベントに Mac のモデル、画面サイズ、タイムゾーンと言語、Wi-Fi 接続かどうか、アプリのバージョン、ビルド、バンドル ID、macOS のバージョン、ライブラリのバージョン、ランダムなセッション ID を加えます。PostHog はリクエストごとに Mac の IP アドレスを受け取り、そこから国や都市などのおおよその位置を割り出します。設定がオンの間、ライブラリは PostHog から設定とフィーチャーフラグも取得します（`/config` と `/flags`）。

サインイン前のイベントには、ライブラリが Mac 上で作るランダムな ID が付き、PostHog はこの ID について個人のプロフィールを作りません。サインインすると、イベントにはアカウント ID が付き、PostHog 上のそのアカウントのプロフィールには、アプリと macOS のバージョン、プロセッサアーキテクチャ、アプリの言語、PostHog が IP アドレスから割り出したおおよその位置が記録されます。これにより、インストールとサインイン、購入が結び付きます。サインアウトすると新しいランダムな ID になります。アプリの利用状況データには、マシン ID、ライセンスの有効化状態、アップデート設定はもう含まれません。

TablePro アカウントに対応する前のバージョンは、代わりに同じ設定のもとで、起動の約 10 秒後、その後は動作中に 1 日 1 回、`api.tablepro.app` へ利用状況レポートを送信します。レポートには次の情報が含まれます。

- マシン ID：Mac のハードウェア UUID の SHA-256 ハッシュ（UUID 自体は送信しません）。
- プラットフォーム、アプリのバージョン、macOS のバージョン、プロセッサアーキテクチャ、アプリの言語。
- 開いている接続のデータベースの種類の名前（例：PostgreSQL）と、開いている接続の数。
- ライセンスが有効化されているかどうか。
- 初めて接続を試みた日時と、初めて接続に成功した日時。
- アップデート設定（インストール方法と確認頻度）。この情報はレポートの到着時に運営者のサーバーが破棄します。

イベントにもレポートにも、ホスト名、ユーザー名、パスワード、クエリ、行データは含まれません。

運営者のサーバーは、レポートも送信元の IP アドレスも保存しません。レポートは、Cloudflare が接続について示す国を付け、ライセンスキーと IP アドレスは付けずに、マシン ID に関するイベントとして PostHog に転送します。PostHog はそこから個人のプロフィールを作りません。アカウントは同じマシン ID でデバイスを管理するため、サインインした Mac やライセンスを有効化した Mac のレポートは、アカウントと関連付けられることがあります。

### ライセンス確認 {#mac-license}

Mac アプリがライセンスサーバーに通信するのは、ライセンスキーの入力後のみです。有効化時、前回の確認から {revalidateDays} 日以上経過した後の起動時、およびその後 {revalidateDays} 日ごとに通信します。各確認では次の情報を送信します。

- ライセンスキー。
- 上記のマシン ID。
- macOS で設定された Mac の名前（お客様の名前が含まれることがあります）。
- アプリと macOS のバージョン。

Mac の有効化を解除する際に送るのは、ライセンスキーとマシン ID のみです。

運営者のサーバーは、有効化した各 Mac を、ライセンスを持つアカウントのデバイスとして保存します。保存するのはマシン ID と名前、アプリと macOS のバージョン、最後に通信した日時です。Mac の有効化と無効化は、リクエストの IP アドレスとユーザーエージェントとともにそのアカウントの監査ログに記録されますが、定期的な確認は記録されません。アカウントポータルにはデバイスの名前が表示されます。サーバーに接続できない場合、有料機能は最後に確認が成功してから {graceDays} 日間使えます。

### TablePro アカウント {#mac-account}

TablePro アカウントに対応したバージョン以降は、ライセンスキーではなく [TablePro アカウント](#account)で Mac アプリにサインインします。アプリはサインインページをブラウザーのウィンドウで開き、そこでサインインメールのコードを入力することもできます。サインイン後、アプリは Mac をアカウントのデバイスとして登録します。登録するのは上記のマシン ID、Mac の名前、プラットフォーム、アプリと macOS のバージョンです。その後、起動中は 1 日 1 回、署名付きファイルとしてプランを運営者のサーバーから取得します。このファイルにより、有料機能はサーバーなしで最大 {offlineDays} 日間使えます。アプリのサインイン状態を保つトークンは、その Mac の macOS キーチェーンにだけ保存され、パスワードの同期をオンにしていても iCloud キーチェーンで同期されることはありません。

Mac にすでにあるライセンスキーは、そのキーを持つアカウントへのサインインと 1 回だけ交換され、その後 Mac から削除されます。180 日間通信のないデバイスは削除されます。デバイスはアプリまたはアカウントポータルで削除でき、Mac が初めてライセンスを使うとメールでお知らせします。

### Team Library {#library}

Team Library は Team ライセンスの機能です。接続で **Share > Publish to Team Library…** を選ぶか、Favorites サイドバーで **Publish Saved Queries to Team…** を選ぶと、Mac アプリは公開する情報を運営者のサーバーへアップロードします。

- 接続設定：ホスト、ポート、データベース名、ユーザー名、SSH と SSL の設定、ドライバーオプション、起動時コマンド、Tunnel Command の設定、Safe Mode レベル、AI 設定。パスワードは含みません。
- 保存済みクエリ：名前、SQL テキスト、キーワード、フォルダー。

TablePro アカウントに対応したバージョン以降、席のある各メンバーの Mac アプリは、起動時、15 分ごと、公開のたびにライブラリの変更をダウンロードします。公開では変更した分だけを送り、その Mac が公開して今はもう持っていない項目だけを削除します。ほかの人が先に項目を変更していた場合は、どちらを残すかを尋ねます。また、各チームクエリを最後に変更した人を表示します。TablePro アカウントに対応する前のバージョンは起動時に、最大でも週に 1 回ライブラリをダウンロードします。公開した Mac は、その直後に再度ダウンロードします。これらのバージョンから再公開すると、以前に公開した内容を置き換えます。アカウントポータルの Library は、ライブラリを閲覧できるメンバーに、各項目を最後に変更した人の名前とともに表示し、オーナーと管理者は項目を削除できます。削除した項目は、すべての Mac が削除を同期できるよう、90 日間運営者のサーバーに残ります。ライセンスが終了しても、チームのオーナーがチームを削除するまでライブラリは運営者のサーバーに残り、チームの削除とともにライブラリも削除されます。

もう一つの Team 機能である Team Catalog は、選択した共有フォルダーにパスワードを含まない接続ファイルを書き込みます。運営者のサーバーを経由しません。

### アップデートとプラグイン {#mac-updates}

- **アップデート確認**。Mac アプリは 1 日 1 回、GitHub（`raw.githubusercontent.com`）から更新フィードをダウンロードします。すべてのウェブリクエストに含まれる IP アドレスと、アプリのバージョンを含む User-Agent 以外に、Mac の情報は送信しません。オフにするには **Settings > General > Software Update** を開き、**Automatically check for updates** のチェックを外します。アップデート自体も GitHub からダウンロードします。
- **プラグインカタログ**。起動時とプラグイン設定を開いたときに、利用可能なドライバーとテーマの一覧を GitHub からダウンロードします。これをオフにする設定はありません。インストールするドライバーとテーマも GitHub からダウンロードし、プラグインブラウザーは GitHub API からダウンロード数を取得します。

これらのリクエストでは GitHub に IP アドレスが送られ、GitHub 独自のプライバシー声明が適用されます。

### お客様が選んで利用するサービス {#mac-third-parties}

Mac アプリは、お客様が設定した場合にのみ次のサービスへ直接データを送信します。TablePro は経由しません。

- **お客様のデータベース、SSH サーバー、プロキシ**は、接続が送信する情報を受け取ります。
- **AI プロバイダー**。プロバイダーを追加し、AI アシスタントまたはインライン提案を使うと、リクエストはそのプロバイダー、または Mac 上で動作するモデルへ送られます。初期設定では、データベースの種類と名前、スキーマのテーブルとカラム定義、現在のクエリが含まれます。結果の行データは、お客様がオンにした場合のみ送られます。プロバイダー自身の規約が適用されます。GitHub Copilot を追加すると、言語サーバーが npm からダウンロードされ、「Send telemetry to GitHub」は初期設定でオンです。
- **ログインサービス**：接続で利用する Microsoft Entra ID、Google、Amazon Web Services、Cloudflare Access。
- **Apple Maps**は、結果を地図に表示する際に地図タイルを提供します。
- **DuckDB**は、クエリで拡張機能を初めて使うときに、その拡張機能を提供します。
- **MCP クライアント**。MCP サーバーは初期設定ではオフです。お客様がオンにするか、設定済みの MCP クライアントが TablePro のブリッジを起動またはペアリングすると開始し、Mac 内（127.0.0.1）のみで待ち受けます。Claude や Cursor などの接続した AI クライアントは、要求した結果を受け取り、独自の規約に従って自社サービスへ送信します。
- **追加した MCP サーバー**。AI セッションは、お客様が承認したツール呼び出しとその引数を、そのサーバーへ送信します。

### Mac 内に残るデータ {#mac-local}

パスワードは macOS キーチェーンに保存されます。接続一覧、クエリ履歴、Query Insights、Data Rewind のスナップショット、設定、開いているタブは Mac に保存されます。SSH キーはディスク上の場所を参照し、コピーはしません。TablePro アカウントに対応する前のバージョンには、クラッシュレポーターや他社のアクセス解析ライブラリは含まれていません。TablePro アカウントに対応したバージョン以降は、上記の利用状況データを送る PostHog のライブラリを含みます。このライブラリには PostHog のクラッシュレポーターが含まれますが、アプリはオフのままにしているため、クラッシュレポートは送信されません。ライブラリは、ランダムな ID、設定、まだ送っていないイベントを `~/Library/Application Support/com.TablePro` 内のファイルに保存します。

## iPhone・iPad 版 TablePro {#ios-app}

初回起動時または **Settings > Privacy** で、**Share Usage Data をオンにしない限り、TablePro へは何も送信されません**。オンにすると、TablePro アカウントに対応する前の Mac アプリと同じサーバーへ 1 日 1 回レポートを送ります。サーバーは同じ方法でレポートを PostHog に転送し、IP アドレスは送りません。レポートには、Apple がデバイス上のアプリに付与する識別子の SHA-256 ハッシュ、プラットフォーム、アプリと iOS のバージョン、プロセッサアーキテクチャ、アプリの言語、開いている接続のデータベースの種類の名前、開いている接続の数、初めて接続を試みた日時、初めて接続に成功した日時、初めてクエリを実行した日時が含まれます。アップデート設定は含まれず、ライセンスは常に「有効化されていない」と報告されます。アプリにはどちらも存在しないためです。

ライセンス確認、アップデート確認、プラグインリクエストは行いません。任意のレポートを除き、接続先はお客様のデータベースと SSH サーバー、iCloud Sync をオンにした場合の Apple の iCloud、SQL Server 接続で Microsoft Entra ID を使う場合の Microsoft のみです。

デバイス上では、パスワードと貼り付けた SSH キーをキーチェーンに保管し、証明書は同期しません。クエリ履歴はデバイス内に残ります。接続はデバイス上の Spotlight インデックスに登録され、検索できます。クエリ実行中は、**Settings > Live Activities > Hide Query** をオンにしない限り、ライブアクティビティがロック画面と展開した Dynamic Island に SQL を表示します。

iPhone または iPad の設定でアプリ開発者と解析情報を共有すると、Apple がクラッシュレポートや利用統計を App Store Connect 経由で運営者へ提供する場合があります。アプリ自体にクラッシュレポーターや他社のアクセス解析ライブラリはありません。

## iCloud Sync と Handoff {#icloud}

iCloud Sync は、Mac と iPhone・iPad のいずれでも、お客様がオンにするまで無効です。オンにすると、記録はお客様の iCloud アカウント内の非公開データベース（コンテナ `iCloud.com.TablePro`）へ保存されます。TablePro は読むことができません。

- Mac では同期対象を選べます。接続、グループ、タグ、設定、SSH プロファイル、認証情報プロファイル（名前とユーザー名のみで、パスワードは含みません）、テーブルとデータベースのお気に入り、保存済みクエリ（SQL テキストを含む）、テーブルフォルダーです。接続の記録にはホスト、ポート、ユーザー名、データベース名、SSH と SSL の設定、起動時コマンド、接続前スクリプト、AI ルールが含まれます。クエリ履歴、Data Rewind のスナップショット、パスワードの取得元は同期しません。
- iPhone・iPad は接続、グループ、タグを同期します。
- パスワードを同期するには、Mac の Sync Categories の **Passwords**、または iPhone・iPad の **Sync Passwords** もオンにする必要があります。iCloud キーチェーンを利用します。Mac では、AI プロバイダーのキーやライセンスキーなど、TablePro がキーチェーンに保存するその他の秘密情報も同期します。TablePro アカウントに対応したバージョン以降、ライセンスキーはサインインと交換された時点で削除され、アプリのサインイン状態を保つトークンは同期されません。

Mac の iCloud Sync は Starter または Team ライセンスの機能です。iPhone・iPad では無料です。

Handoff は Apple を通じて、お客様自身のデバイス間で、開いている接続の ID とテーブル名を渡します。テーブルを開いていない場合は接続名を、名前がない場合はホストを渡します。設定や認証情報は送信しません。

## ウェブサイト {#website}

**ホスティング**。ウェブサイトとアカウントポータルは Cloudflare の背後にある運営者のサーバーで動作します。一般的なウェブサーバーと同様、IP アドレス、ブラウザーの User-Agent、要求した各ページのアドレスを受け取ります。

**Cloudflare Web Analytics**。Cloudflare はウェブサイトのページに Web Analytics スクリプトを追加します。アカウントポータルでは実行されません。ブラウザーは `static.cloudflareinsights.com` から読み込み、ページ、リンク元サイト、読み込み時間、ブラウザー、OS、デバイスの種類をページ閲覧ごとに Cloudflare へ報告します。Cloudflare は接続元の国も追加します。スクリプトは Cookie を設定せず、ブラウザーにも何も保存しません。Cloudflare は、IP アドレスやブラウザーの情報をフィンガープリントによる識別に使わないとしています。運営者に提供されるのは、ページ別・国別の閲覧数などの集計値で、訪問者個別の記録ではありません。法的根拠：正当な利益。

**Google Analytics**。サイトはすべてのページで Consent Mode の Google Analytics を読み込みます。Cookie の質問で**許可**を選ぶまでは Cookie を設定せず、デバイスに識別子を保存することなく、ページごとに Cookie を使わないシグナルのみを Google に送ります。許可すると `_ga` と `_ga_<ID>` Cookie を設定し、閲覧ページ、ダウンロードのクリック、チェックアウトの開始などを計測します。広告用ストレージ、広告のパーソナライズ、広告用ユーザーデータは常に拒否します。Google は Google Analytics 4 が IP アドレスを記録・保存しないとしています。運営者のプロパティは Google の初期設定の保存期間を使用し、Google は収集したユーザー単位・イベント単位のデータを 2 か月後に削除します。識別子ではなく集計値を保持する標準レポートは影響を受けません。法的根拠：Cookie へのお客様の同意。

**チャット**。ウェブサイトとアカウントポータルのすべてのページに、チャットプロバイダー Crisp のボタンを表示します。ページの読み込み後、ブラウザーは `client.crisp.chat` からスクリプトを読み込み、Crisp は [Cookie とブラウザーストレージ](#cookies)に記載する Cookie を設定します。Crisp は IP アドレス、ブラウザーの情報、閲覧ページのアドレス、入力したメッセージを受け取り、会話を始めた場合は IP アドレスを保持します。運営者はページの言語を Crisp に伝えます。アカウントポータルにログインしている場合は、会話をアカウントと結び付けるため、アカウントのメールアドレスとアカウント ID も Crisp に伝えます。お客様に関するその他の情報は伝えません。Crisp の所在地はフランスです。

**チェックアウトスクリプト**。購入ボタンにポインタを合わせるか Tab キーでフォーカスすると、ブラウザーは jsDelivr（`cdn.jsdelivr.net`）から {merchant} のスクリプトを読み込みます。jsDelivr は IP アドレスとブラウザーの情報を受け取ります。{merchant} のチェックアウト自体が開くのはクリックしたときだけです。

**ニュースレターの確認**。ニュースレターのフォームに入力し始めると、登録するのが人であることを確かめるため、ブラウザーは `challenges.cloudflare.com` から Cloudflare Turnstile を読み込みます。Cloudflare は IP アドレスとブラウザーの情報を受け取ります。

**購入の流入元**。サイトに到着すると、ブラウザーは初回訪問の記録を `tablepro:attribution` としてローカルストレージに 90 日間保存します。記録は訪問元（アクセスしたリンクの `ref`・`utm_*` タグ、またはリンク元サイト）、最初に開いたページ、日時です。購入を開始するとチェックアウトリクエストとともに送られます。運営者のサーバーは訪問元をチェックアウトのメタデータとして {merchant} に渡し、支払い後は注文とともに保存し、チェックアウトと支払いのイベントとともに PostHog に送ります。最初に開いたページと日時は保存しません。

**ドキュメント**。docs.tablepro.app のドキュメントは Mintlify がホストしています。Mintlify はページごとにお客様の IP アドレスとブラウザーの情報を受け取り、ページは Google Fonts からフォントを読み込みます。ナビゲーションバーにはリポジトリの Star 数が表示され、お客様のブラウザーがそれを GitHub の API から取得します。そのため GitHub もお客様の IP アドレスとブラウザーの情報を受け取ります。このリクエストは Cookie を設定しません。ドキュメントは、このサイトでの回答を読み取れないため、独自に Cookie の質問を表示します。そこで **Allow** を選ぶまでは Cookie を設定せず、訪問者 ID も保存しません。許可すると、Google Analytics が `_ga` と `_ga_<ID>` Cookie を設定してドキュメントの閲覧を計測し、Mintlify は集計のためにランダムな訪問者 ID `mintlify_anonymous_id` をローカルストレージに保存します。ドキュメントのフッターにある **Cookie settings** で回答を変更でき、拒否すると両方が削除されます。法的根拠：お客様の同意。

**言語と地域割引**。ブラウザーの言語にサイトの対応言語が含まれない場合にページを適切な言語で提案するため、またチェックアウトで適用される地域割引を表示するため、サイトは Cloudflare（`/cdn-cgi/trace`）と運営者のサーバーに接続元の国を問い合わせ、デバイスのタイムゾーンを読み取ることがあります。どちらのリクエストにも Cookie は含まれず、ページは応答の内容を保存しません。法的根拠：正当な利益。

サイトの閲覧では、サイト独自の Cookie は設定されません。公開サイトからのニュースレター登録、チェックアウト、割引コード確認のリクエストは認証情報を含めないため、アカウントポータルの Cookie を送信せず、応答の Cookie も受け入れません。アカウントポータルのページを開く操作は別で、そこでサインインすると以下のポータル Cookie が設定されます。サイトがブラウザーに保持する情報はすべて [Cookie とブラウザーストレージ](#cookies)に掲載しています。

## アカウントポータル {#account}

account.tablepro.app の[アカウントポータル]({account})では、TablePro アカウントのライセンス、デバイス、請求、チームを管理できます。ウェブサイトと同じく、Cloudflare の背後にある運営者のサーバーで動いています。

**アカウント**。アカウントは 1 人の利用者のもので、メールアドレスで識別します。アカウントには、そのアドレス、設定した名前と言語、サインイン方法、サインインしているデバイス、ライセンスと注文、所属するチームと役割・シート、そしてサインイン、新しいデバイス、チームの変更など、アカウントへの変更を記録した監査ログが、各変更を行ったリクエストの IP アドレスとブラウザーとともに含まれます。メールはアカウントの言語でお届けします。

**サインイン**。リンクと 6 桁のコードをメールでお送りします。リンクは 1 回だけ使え、コードは 5 回まで試せ、どちらも 15 分で失効します。パスキーを追加することもできます。パスキーごとに、公開鍵、付けた名前、デバイス間で同期されるかどうか、追加日時と最終使用日時を保存します。Apple、GitHub、Google でサインインすることもできます。その場合、プロバイダーはお客様の ID と確認済みのメールアドレスを、Apple は初回に名前も運営者に伝えます。ID とアドレスはアカウントとともに保存し、Apple についてはトークンを暗号化して保存し、Apple の連携を解除したときやアカウントを削除したときに Apple で失効させます。プロバイダーのアドレスが既存のアカウントのものである場合、連携する前にそのアカウントへ確認用のリンクとコードを送ります。ただし、Google がそのアドレスを管理している場合（Gmail または Google Workspace）は除きます。

**チーム**。誰かをチームに招待すると、その人のメールアドレス、役割、招待にシートが含まれるかどうかを保存し、7 日間有効なリンクを送ります。オーナーと管理者は、チームのメンバーの名前とメールアドレス、招待、チームの監査ログを見られます。監査ログには、招待したアドレスを含め、チームで誰が何を変更したかが表示されますが、IP アドレスやブラウザーは表示されません。メンバーは、チーム、そのプラン、シート数、自分の役割を見られます。

**データ**。設定画面では、名前、メールアドレス、言語の変更、サインイン方法の追加と削除、アカウントのデータの JSON ファイルでのダウンロード、アカウントの削除ができます。ほかのメンバーがいるチームのオーナーである間は削除できません。削除すると、サインイン方法、デバイス、ライセンス、チームのメンバーシップ、自分だけのチームが削除され、サブスクリプションは返金なしで終了します。削除後に保存するものは[データの保存期間](#retention)をご覧ください。

**ポータルが読み込むもの**。ポータルは Google Analytics も Cloudflare Web Analytics も、その他の解析スクリプトも読み込まず、Cookie についての質問も表示しません。[ウェブサイト](#website)で説明した Crisp のチャットを表示し、ポータルで購入すると {merchant} のチェックアウトがページの上に開きます。エラーと読み込み時間は Grafana Faro で Grafana Cloud に報告します。報告するのは、エラー、発生した画面（リンクのトークンを含むことがある完全なアドレスは送りません）、ブラウザーと OS、訪問ごとのランダムな ID です。

## ニュースレター {#newsletter}

リリースノートを購読すると、まず登録したページの言語で確認リンクをメールで送ります。リンクは 7 日間有効で、1 つのアドレスに送るのは 1 日 3 通までです。確認すると、アドレスは運営者のメールを送信するサービス Resend のニュースレターリストに加わります。すべてのニュースレターに配信停止リンクがあり、Resend が処理します。配信停止後はニュースレターを送りません。メールアドレス自体の削除も希望する場合は、ご連絡ください。フォームは、[ウェブサイト](#website)で説明したとおり Cloudflare Turnstile が確認します。

## Cookie とブラウザーストレージ {#cookies}

公開サイトの閲覧では、サイト独自の Cookie は設定しません。ニュースレター登録、チェックアウト、割引コード確認のリクエストは認証情報を含めず、ポータル Cookie を設定しません。アカウントポータルにサインインすると、またはサインインを始めると、以下の厳密に必要な Cookie が 1 つ設定されます。Cloudflare Web Analytics は Cookie を設定せず、ブラウザーにも何も保存しません。Google Analytics の Cookie は許可するまで設定されません。Crisp はチャットの読み込み後、すべてのページで Cookie を設定します。ここに記載する情報は広告に利用されず、販売もされません。

- **`_ga` と `_ga_<ID>`**（Google Analytics の Cookie、最長 2 年、解析を許可した場合のみ）：ブラウザーのランダムな識別子と現在の訪問状態です。拒否した場合や後から回答を変更した場合は削除します。法的根拠：同意。
- **`tablepro:analytics-consent`**（ローカルストレージ、消去するまで）：解析の質問への回答を保存し、ページごとに質問しないようにします。アカウントポータルは解析を行わないため、この質問をせず、回答も読みません。法的根拠：お客様の選択を尊重するために厳密に必要。
- **`tablepro:attribution`**（ローカルストレージ、90 日）：[ウェブサイト](#website)で説明した初回訪問の記録です。お客様の識別子は含まず、チェックアウトリクエストとともにのみ送られ、サーバーは訪問元を {merchant} に渡します。法的根拠：正当な利益。
- **`theme`**（ローカルストレージ、消去するまで）：ライト、ダーク、システムの表示設定を保存します。アカウントポータルは独自の設定を保存します。法的根拠：正当な利益。
- **`tablepro:language`**（ローカルストレージ、消去するまで）：言語メニューまたは言語バーで選んだ言語と、提案を閉じた言語を保存し、同じ言語を再び提案しないようにします。法的根拠：正当な利益。
- **`mintlify_anonymous_id`**（docs.tablepro.app のローカルストレージ、Mintlify が設定、そこで Google Analytics を許可した場合のみ）：[ウェブサイト](#website)で説明した訪問者 ID です。拒否すると削除されます。ドキュメントは独自の `tablepro:analytics-consent` の回答を保存します。法的根拠：同意。
- **`crisp-client/` で始まる Cookie**（Crisp、例：`crisp-client/session/…`、6 か月、再訪時に更新、チャット読み込み後はすべてのページで設定）：ページや訪問をまたいでチャットと会話を維持します。法的根拠：すべてのページでサポートを提供するための正当な利益。
- **`__Host-tp_session`**（アカウントポータルの Cookie、サインインから 30 日）：サインイン状態を維持します。サインイン前は、パスキー、Apple、GitHub、Google、またはアプリからのサインインの途中にのみ、最大 10 分間設定されます。サインアウトすると削除されます。公開サイトからのニュースレター登録、チェックアウト、割引コード確認のリクエストは認証情報を含めず、この Cookie を受け取りません。法的根拠：厳密に必要。
- **`locale`、`context`、`sign-in-return-to`**（アカウントポータルのローカルストレージ）：サインイン前にポータルで選んだ言語と、最後に開いたのが個人とチームのどちらか（いずれも消去するまで）、そしてメールのサインインリンクを開いた後に戻るページ（15 分）です。法的根拠：正当な利益。
- **`com.grafana.faro.session`**（アカウントポータルのセッションストレージ、タブを閉じるまで）：ポータルのエラー報告に使う、訪問ごとのランダムな ID です。法的根拠：正当な利益。

## データの保存期間 {#retention}

- **利用状況レポートと分析イベント**：運営者のサーバーは PostHog に転送した後、コピーを保存しません。PostHog での保存期間の上限は設定していません。アカウントを削除すると、その PostHog のプロフィールとイベントは 1 時間後に削除されます。
- **以前のサーバーの記録**：以前のサーバーのデータベース全体のコピーを、期限を定めずにアーカイブに保存しています。これには、メールアドレスと名前を含むライセンス、注文、チームメンバー、ライセンスで有効化された Mac とその名前、ニュースレターの購読者とベータ版の登録者、送信したメールの記録、そして以前のサーバーが保存していた利用状況レポートとライセンスリクエストの記録（IP アドレスを含む）が含まれます。
- **デバイス**：使用している間は保存します。180 日間通信のないデバイスは、有効なオフラインファイルが残っていない限り削除し、削除したデバイスは 1 年後に消去します。
- **アカウントの監査ログ**：アカウントがある間は、お客様が行った各変更の IP アドレスとブラウザーとともに保存します。アカウントを削除すると、メールアドレスと、お客様の操作の IP アドレスとブラウザーがログから削除されます。各変更の記録自体は残ります。
- **注文**：税務・会計のため保存します。アカウントを削除すると、注文からメールアドレスとアカウントが削除されます。
- **{merchant}、Resend、Apple からの通知**：180 日。{merchant} の通知には名前、メールアドレス、請求先住所が含まれます。アカウントを削除すると、購入に関する通知からはそれらが早めに削除されます。
- **Team Library**：項目が変更または削除されるまで。削除した項目は 90 日間保存します。ライブラリはチームとともに削除され、ライセンスが終了しても残ります。
- **サインインのリンクとコード**：15 分で失効し、その 7 日後に削除します。ポータルのセッションは 30 日です。アプリのサインイン状態を保つトークンは、アプリが最後に使ってから 90 日で失効し、その 30 日後に削除します。
- **削除されたアカウント**：アカウント、サインイン方法、デバイス、ライセンス、チームのメンバーシップは直ちに削除します。注文と監査ログは上記のとおり残ります。以前のサーバーが保存していたお客様に関する情報は、上記のアーカイブに残ります。
- **ニュースレター**：確認リンクとその送信先アドレスは、リンクの失効から 7 日後に削除します。確認済みのアドレスと以前のサーバーから移行したアドレスは、ご依頼により削除するまで Resend のリストに残ります。配信停止後は、ニュースレターが届かないよう配信停止済みとして保存されます。
- **Google Analytics**：ユーザー単位・イベント単位のデータは 2 か月。運営者のプロパティが使用する Google の初期設定の期間です。Cookie は最長 2 年保持され、拒否した場合は削除されます。
- **Cloudflare Web Analytics**：運営者には直近 6 か月のページ閲覧の集計値を表示します。ブラウザーには何も保存しません。
- **チャットとサポートメール**：削除するまで Crisp と運営者のメールボックスに保存します。会話やメールの削除をご希望の場合はご連絡ください。
- **ウェブサーバーログ**：セキュリティと問題解決のため保存します。固定の期間はまだ設定していません。
- **運営者のサーバーのログとトレース、ポータルのエラー報告**：Grafana Cloud で 14 日間。

## セキュリティ {#security}

アプリ、ウェブサイト、アカウントポータル、運営者のサーバーの間の通信には HTTPS を使用します。TablePro アカウントにパスワードはありません。サインインのリンクとコード、アプリのサインイン状態を保つトークン、チームの API トークンはハッシュで保存します。ただし、サインインのリンクとコードをメールで送るジョブは、ジョブが削除されるまでそれらを平文で保持します。削除はメール送信の 1 日後、送信を断念した場合はその 7 日後です。リンクとコードはどちらも、リクエストから 15 分後に使えなくなります。システムへのアクセスは {publisherName} と、[データの受領者](#sharing)に記載したサービス提供者に限定します。完全に安全なシステムはありません。脆弱性の報告は、[セキュリティページ](/ja/security#report)の案内に従って行うか、[{email}](mailto:{email}) にお送りください。
