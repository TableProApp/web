이 방침은 Mac용 TablePro, iPhone 및 iPad용 TablePro, tablepro.app 웹사이트, docs.tablepro.app 문서 및 account.tablepro.app 계정 포털에 적용됩니다. 각 제품이 현재 실제로 전송하고 저장하는 정보를 설명합니다. 두 앱은 모두 AGPLv3로 공개된 오픈 소스이므로 아래 데이터를 전송하는 코드를 [TablePro 저장소]({github})에서 확인할 수 있습니다.

## 요약 {#summary}

- Mac 앱은 하루에 한 번 TablePro에 사용 보고서를 보냅니다. 기본적으로 켜져 있으며 끌 수 있습니다. iPhone 및 iPad 앱은 사용자가 켜는 경우에만 보냅니다.
- TablePro 계정에 로그인하거나 라이선스 키를 활성화하면 Mac 앱은 Mac을 이름과 함께 운영자의 서버에 등록하고 정기적으로 플랜을 확인합니다.
- 실행한 쿼리, 결과 및 비밀번호는 TablePro에 전송되지 않습니다. 예외는 Team Library에 직접 게시하는 연결 설정(비밀번호는 제외)과 저장된 쿼리입니다.
- AI 요청은 Mac 앱에서 설정한 AI 제공업체로 직접 전송되며 운영자를 거치지 않습니다.
- 운영자의 서버는 사용 보고서를 IP 주소 없이 EU에 있는 제품 분석 서비스 PostHog로 전달합니다. TablePro 계정을 지원하는 버전부터 Mac 앱은 보고서를 PostHog로 직접 보내므로 PostHog가 Mac의 IP 주소를 받습니다. 계정에는 로그인과 새 기기 같은 계정 변경 기록이 각 변경을 만든 요청의 IP 주소 및 브라우저와 함께 남습니다.
- 웹사이트는 쿠키를 설정하지 않는 Cloudflare Web Analytics로 페이지 조회 수를 집계합니다. Google Analytics도 로드하며 쿠키는 사용자가 허용한 경우에만 설정합니다. 모든 페이지에서 실시간 채팅 서비스인 Crisp도 로드하며, Crisp는 자체 쿠키를 설정합니다.
- account.tablepro.app의 계정 포털은 분석 스크립트를 로드하지 않습니다. 로그인 상태를 유지하는 쿠키 하나를 설정하며, 설정에서 계정 데이터를 다운로드하거나 계정을 삭제할 수 있습니다.
- 구매는 merchant of record인 {merchant}를 통해 이루어집니다.

## 책임 주체 {#controller}

여기에 설명된 개인정보의 책임 주체(개인정보처리자)는 TablePro 앱과 이 웹사이트를 배포하는 {publisherCountry} {publisherCity}의 개인 개발자 {publisherName}(이하 "운영자")입니다. 이 방침 또는 개인정보에 관한 질문은 [{email}](mailto:{email})로 이메일을 보내주세요.

## Mac용 TablePro {#mac-app}

### 사용 보고서 {#mac-usage-report}

Mac 앱은 시작 후 약 10초 뒤, 이후 실행 중에는 하루에 한 번 `api.tablepro.app`에 사용 보고서를 보냅니다. **기본적으로 켜져 있으며 첫 보고서를 보내기 전에 허락을 요청하지 않습니다.** 끄려면 **설정 > 일반 > 개인정보 보호**(Settings > General > Privacy)에서 **익명 사용 데이터 공유**(Share anonymous usage data)를 해제하세요.

보고서에는 다음 정보가 포함됩니다.

- 기기 ID: Mac 하드웨어 UUID의 SHA-256 해시(UUID 자체는 전송되지 않음)
- 플랫폼, 앱 버전, macOS 버전, 프로세서 아키텍처 및 앱 언어
- 열려 있는 연결의 데이터베이스 유형 이름(예: PostgreSQL) 및 열려 있는 연결 수
- 라이선스 활성화 여부
- 처음 연결을 시도한 날짜와 시간 및 처음 연결에 성공한 날짜와 시간
- 업데이트 설정(설치 방식과 확인 빈도). 운영자의 서버는 보고서가 도착하면 이 정보를 폐기합니다.

호스트 이름, 사용자 이름, 비밀번호, 쿼리 또는 행 데이터는 포함하지 않습니다.

운영자의 서버는 보고서도, 보고서를 보낸 IP 주소도 저장하지 않습니다. 보고서는 Cloudflare가 연결에 대해 알려주는 국가를 붙이고 라이선스 키와 IP 주소는 빼고 기기 ID에 관한 이벤트로 PostHog에 전달하며, PostHog는 이를 바탕으로 개인 프로필을 만들지 않습니다. 계정은 같은 기기 ID로 기기를 관리하므로 로그인했거나 라이선스를 활성화한 Mac의 보고서는 계정과 연결될 수 있습니다.

TablePro 계정을 지원하는 버전부터 Mac 앱은 같은 설정에 따라 사용 데이터를 PostHog로 직접 보냅니다. 이때 PostHog는 Mac의 IP 주소를 받습니다. 로그인하면 이 데이터를 계정 ID와 연결해 설치를 로그인 및 구매와 이어 줍니다. 설정을 끄면 둘 다 멈춥니다.

### 라이선스 확인 {#mac-license}

Mac 앱은 라이선스 키를 입력한 후에만 라이선스 서버에 접속합니다. 라이선스 활성화 시, 마지막 확인 후 {revalidateDays}일 이상 지났을 때 앱을 시작하면, 그리고 이후 {revalidateDays}일마다 확인합니다. 각 확인 요청에는 다음 정보가 포함됩니다.

- 라이선스 키
- 위에서 설명한 기기 ID
- macOS에 설정된 Mac 이름(사용자의 이름이 포함되는 경우가 많음)
- 앱 버전 및 macOS 버전

Mac 활성화 해제 시에는 라이선스 키와 기기 ID만 전송합니다.

운영자의 서버는 활성화된 각 Mac을 라이선스를 가진 계정의 기기로 저장합니다. 저장하는 항목은 기기 ID와 이름, 앱 및 macOS 버전, 마지막으로 통신한 시간입니다. Mac의 활성화와 비활성화는 요청의 IP 주소 및 사용자 에이전트와 함께 해당 계정의 감사 로그에 기록되지만 정기 확인은 기록되지 않습니다. 계정 포털에는 기기가 이름으로 표시됩니다. 서버에 연결할 수 없는 경우 마지막 확인에 성공한 날부터 {graceDays}일 동안 유료 기능이 계속 작동합니다.

### TablePro 계정 {#mac-account}

TablePro 계정을 지원하는 버전부터는 라이선스 키 대신 [TablePro 계정](#account)으로 Mac 앱에 로그인합니다. 앱은 로그인 페이지를 브라우저 창에서 열며, 그곳에서 로그인 이메일의 코드를 입력할 수도 있습니다. 로그인하면 앱은 Mac을 계정의 기기로 등록합니다. 등록하는 항목은 위에서 설명한 기기 ID, Mac 이름, 플랫폼, 앱 및 macOS 버전입니다. 이후 실행 중에는 하루에 한 번 서명된 파일 형태로 운영자의 서버에서 플랜을 가져오며, 이 파일로 유료 기능은 서버 없이 최대 14일 동안 작동합니다. 앱의 로그인 상태를 유지하는 토큰은 macOS 키체인에 보관됩니다.

Mac에 이미 있는 라이선스 키는 해당 키를 가진 계정으로의 로그인과 한 번만 교환된 후 Mac에서 삭제됩니다. 180일 동안 통신하지 않은 기기는 제거됩니다. 기기는 앱이나 계정 포털에서 제거할 수 있으며, Mac이 처음으로 라이선스를 사용하면 이메일로 알려드립니다.

### Team Library {#library}

Team Library는 Team 라이선스에 포함됩니다. 연결에서 **공유 > 팀 라이브러리에 게시…**(Share > Publish to Team Library…)를 선택하거나 Favorites 사이드바에서 **저장된 쿼리를 팀에 게시…**(Publish Saved Queries to Team…)를 선택하면 Mac 앱은 게시할 내용을 운영자의 서버에 업로드합니다.

- 연결 설정: 호스트, 포트, 데이터베이스 이름, 사용자 이름, SSH 및 SSL 설정, 드라이버 옵션, 시작 명령, Tunnel Command 설정, Safe Mode 수준 및 AI 설정. 비밀번호는 포함하지 않습니다.
- 저장된 쿼리: 이름, SQL 텍스트, 키워드 및 폴더

같은 Team 라이선스의 Mac은 시작할 때 라이브러리를 다운로드하며 최대 일주일에 한 번입니다. 게시한 Mac은 게시 직후 다시 다운로드합니다. 다시 게시하면 이전에 게시한 내용을 대체합니다. 계정 포털의 Library는 라이브러리를 읽을 수 있는 구성원에게 각 항목을 마지막으로 변경한 사람의 이름과 함께 보여 주며, 소유자와 관리자는 항목을 삭제할 수 있습니다. 삭제한 항목은 모든 Mac이 삭제를 동기화할 수 있도록 90일 동안 운영자의 서버에 남습니다. 라이선스가 끝나도 팀 소유자가 팀을 삭제할 때까지 라이브러리는 운영자의 서버에 남으며, 팀을 삭제하면 라이브러리도 함께 삭제됩니다.

다른 Team 기능인 Team Catalog는 선택한 공유 폴더에 비밀번호가 없는 연결 파일을 저장합니다. 운영자의 서버를 거치지 않습니다.

### 업데이트 및 플러그인 {#mac-updates}

- **업데이트 확인.** Mac 앱은 하루에 한 번 GitHub(`raw.githubusercontent.com`)에서 업데이트 피드를 다운로드합니다. 요청에는 일반적인 웹 요청에 포함되는 IP 주소 및 앱 버전이 포함된 사용자 에이전트 외에 Mac 정보가 포함되지 않습니다. 끄려면 **설정 > 일반 > 소프트웨어 업데이트**(Settings > General > Software Update)에서 **업데이트 자동 확인**(Automatically check for updates)을 해제하세요. 업데이트 자체도 GitHub에서 다운로드합니다.
- **플러그인 카탈로그.** 앱 시작 시와 플러그인 설정을 열 때 GitHub에서 이용 가능한 드라이버와 테마 목록을 다운로드합니다. 이를 끄는 설정은 없습니다. 설치하는 드라이버와 테마는 GitHub에서 다운로드하며, 플러그인 브라우저는 GitHub API에서 다운로드 수를 읽습니다.

GitHub는 이 요청과 함께 IP 주소를 받습니다. 해당 요청에는 GitHub의 개인정보 처리방침이 적용됩니다.

### 사용자가 선택하는 서비스 {#mac-third-parties}

Mac 앱은 아래 서비스를 설정한 경우에만 데이터를 직접 전송하며 TablePro를 거치지 않습니다.

- **사용자의 데이터베이스, SSH 서버 및 프록시**는 해당 연결이 보내는 정보를 받습니다.
- **AI 제공업체.** 제공업체를 추가하고 AI 어시스턴트 또는 인라인 제안을 사용하면 요청은 해당 제공업체 또는 Mac에서 실행되는 모델로 전달됩니다. 기본적으로 데이터베이스 유형과 이름, 스키마의 테이블 및 열 정의, 현재 쿼리가 포함됩니다. 결과 행은 사용자가 해당 옵션을 켠 경우에만 전송됩니다. 제공업체의 약관이 적용됩니다. GitHub Copilot을 추가하면 npm에서 언어 서버를 다운로드하며 "GitHub에 텔레메트리 보내기"(Send telemetry to GitHub) 설정은 처음부터 켜져 있습니다.
- **로그인 서비스**: 연결에서 사용하는 경우 Microsoft Entra ID, Google, Amazon Web Services 및 Cloudflare Access.
- **Apple Maps**는 결과를 지도에 표시할 때 지도 타일을 제공합니다.
- **DuckDB**는 쿼리가 확장 기능을 처음 사용할 때 해당 확장을 제공합니다.
- **MCP 클라이언트.** MCP 서버는 기본적으로 꺼져 있습니다. 사용자가 켜거나 설정한 MCP 클라이언트가 TablePro 브리지를 실행하거나 페어링하면 시작되며, Mac 내부(127.0.0.1)에서만 수신합니다. Claude 또는 Cursor 같은 연결된 AI 클라이언트는 요청한 결과를 받고 자체 약관에 따라 자체 서비스로 보냅니다.
- **추가한 MCP 서버.** AI 세션은 사용자가 승인한 도구 호출과 인수를 해당 서버로 보냅니다.

### Mac에 남는 데이터 {#mac-local}

비밀번호는 macOS 키체인에 보관됩니다. 연결 목록, 쿼리 기록, Query Insights, Data Rewind 스냅샷, 설정 및 열린 탭은 Mac에 저장됩니다. 앱은 디스크의 SSH 키 위치를 참조하며 복사하지 않습니다. 앱에는 충돌 보고 도구나 타사 분석 라이브러리가 없습니다.

## iPhone 및 iPad용 TablePro {#ios-app}

앱을 처음 시작할 때 또는 이후 **설정 > 개인정보 보호**(Settings > Privacy)에서 **사용 데이터 공유(Share Usage Data)를 켜지 않으면 아무것도 TablePro에 전송되지 않습니다**. 켜면 Mac 앱과 같은 서버에 하루에 한 번 보고서를 보내며, 서버는 같은 방식으로 보고서를 IP 주소 없이 PostHog에 전달합니다. 보고서에는 Apple이 기기의 앱에 부여한 식별자의 SHA-256 해시, 플랫폼, 앱 및 iOS 버전, 프로세서 아키텍처, 앱 언어, 열려 있는 연결의 데이터베이스 유형 이름, 열려 있는 연결 수, 그리고 처음 연결을 시도한 날짜와 시간, 처음 연결에 성공한 날짜와 시간 및 첫 쿼리를 실행한 날짜와 시간이 포함됩니다. 앱에는 업데이트 설정과 라이선스가 없으므로 업데이트 설정은 포함되지 않으며 라이선스는 항상 활성화되지 않은 것으로 보고됩니다.

앱은 라이선스 확인, 업데이트 확인 및 플러그인 요청을 하지 않습니다. 선택적 보고서 외에는 사용자의 데이터베이스와 SSH 서버, iCloud Sync를 켠 경우 Apple의 iCloud, SQL Server 연결에서 Microsoft Entra ID로 로그인하는 경우 Microsoft에만 연결합니다.

기기에서는 비밀번호와 붙여 넣은 SSH 키를 키체인에 보관하며 인증서는 동기화하지 않습니다. 쿼리 기록은 기기에 남습니다. 연결은 기기의 Spotlight 색인에 추가되어 검색할 수 있습니다. 쿼리 실행 중에는 **설정 > 실시간 현황 > 쿼리 가리기**(Settings > Live Activities > Hide Query)를 켜지 않으면 실시간 현황이 잠금 화면과 확장된 Dynamic Island에 SQL을 표시합니다.

iPhone 또는 iPad 설정에서 앱 개발자와 분석 정보를 공유하면 Apple이 App Store Connect를 통해 충돌 보고서와 사용 통계를 제공할 수 있습니다. 앱 자체에는 충돌 보고 도구나 타사 분석 라이브러리가 없습니다.

## iCloud Sync 및 Handoff {#icloud}

iCloud Sync는 Mac과 iPhone 및 iPad에서 사용자가 켤 때까지 꺼져 있습니다. 켜면 기록이 사용자의 iCloud 계정 내 비공개 데이터베이스(컨테이너 `iCloud.com.TablePro`)로 전송됩니다. TablePro는 이를 읽을 수 없습니다.

- Mac에서는 연결, 그룹과 태그, 설정, SSH 프로필, 인증 정보 프로필(이름과 사용자 이름만, 비밀번호 제외), 테이블 및 데이터베이스 즐겨찾기, 저장된 쿼리(SQL 텍스트 포함) 및 테이블 폴더 중 동기화할 항목을 선택합니다. 연결 기록에는 호스트, 포트, 사용자 이름, 데이터베이스 이름, SSH 및 SSL 설정, 시작 명령, 연결 전 스크립트 및 AI 규칙이 포함됩니다. 쿼리 기록, Data Rewind 스냅샷 및 비밀번호 출처는 동기화하지 않습니다.
- iPhone 및 iPad는 연결, 그룹 및 태그를 동기화합니다.
- 비밀번호를 동기화하려면 Mac의 Sync Categories에서 **암호**(Passwords)를, 또는 iPhone 및 iPad에서 **암호 동기화**(Sync Passwords)를 추가로 켜야 하며 iCloud 키체인을 사용합니다. Mac에서는 AI 제공업체 키와 라이선스 키 등 TablePro가 키체인에 보관하는 다른 비밀 정보도 동기화합니다.

Mac의 iCloud Sync는 Starter 또는 Team 라이선스에 포함됩니다. iPhone 및 iPad에서는 무료입니다.

Handoff는 Apple을 통해 사용자 자신의 기기 간에 열린 연결의 ID와 열린 테이블 이름을 전달합니다. 열린 테이블이 없으면 연결 이름을 전달하며, 연결에 이름이 없으면 호스트를 전달합니다. 설정이나 인증 정보는 보내지 않습니다.

## 웹사이트 {#website}

**호스팅.** 웹사이트와 계정 포털은 Cloudflare 뒤에 있는 운영자의 서버에서 실행됩니다. 일반적인 웹 서버처럼 IP 주소, 브라우저 사용자 에이전트 및 요청한 각 페이지의 주소를 받습니다.

**Cloudflare Web Analytics.** Cloudflare는 웹사이트 페이지에 Web Analytics 스크립트를 추가하며, 계정 포털에서는 실행되지 않습니다. 브라우저는 `static.cloudflareinsights.com`에서 이를 로드하고 페이지 조회마다 페이지, 유입 사이트, 로딩 시간, 브라우저, 운영체제 및 기기 유형을 Cloudflare에 보고합니다. Cloudflare는 연결 국가를 추가합니다. 스크립트는 쿠키를 설정하거나 브라우저에 정보를 저장하지 않습니다. Cloudflare는 IP 주소나 브라우저 정보를 이용해 사용자를 핑거프린팅하지 않는다고 명시합니다. 운영자는 방문자별 기록 대신 페이지별 또는 국가별 조회 수 같은 집계만 받습니다. 법적 근거: 정당한 이익.

**Google Analytics.** 사이트는 모든 페이지에서 동의 모드로 Google Analytics를 로드합니다. 쿠키 질문에서 **허용**을 선택하기 전에는 쿠키를 설정하지 않고 기기에 식별자를 저장하지 않은 채 페이지마다 쿠키 없는 신호만 Google에 보냅니다. 허용하면 `_ga` 및 `_ga_<ID>` 쿠키를 설정하고 조회 페이지, 다운로드 클릭 및 결제 시작 같은 방문 활동을 측정합니다. 광고 저장소, 광고 개인화 및 광고 사용자 데이터는 항상 거부됩니다. Google은 Google Analytics 4가 IP 주소를 기록하거나 저장하지 않는다고 명시합니다. 운영자의 Google Analytics 속성은 Google의 기본 보관 기간을 사용하므로 Google은 수집한 사용자 수준 및 이벤트 수준 데이터를 2개월 후 삭제합니다. 식별자 대신 집계를 보관하는 Google 표준 보고서는 영향을 받지 않습니다. 법적 근거: 쿠키에 대한 동의.

**실시간 채팅.** 웹사이트와 계정 포털의 모든 페이지에는 채팅 제공업체 Crisp의 버튼이 표시됩니다. 페이지 로딩 후 브라우저는 `client.crisp.chat`에서 Crisp 스크립트를 로드하고, Crisp는 [쿠키 및 브라우저 저장소](#cookies)에 설명된 쿠키를 설정합니다. Crisp는 IP 주소, 브라우저 정보, 조회 페이지 주소 및 작성한 메시지를 받으며, 대화를 시작하면 IP 주소를 보관합니다. 운영자는 Crisp에 페이지 언어를 알려줍니다. 계정 포털에 로그인한 경우에는 대화를 계정과 연결하기 위해 계정의 이메일 주소와 계정 ID도 Crisp에 제공합니다. 그 외 사용자 정보는 제공하지 않습니다. Crisp는 프랑스에 있습니다.

**결제 스크립트.** 구매 버튼에 포인터를 올리거나 Tab 키로 이동하면 브라우저는 jsDelivr(`cdn.jsdelivr.net`)에서 {merchant}의 결제 스크립트를 로드합니다. jsDelivr는 IP 주소와 브라우저 정보를 받습니다. {merchant}의 결제 화면 자체는 클릭할 때만 열립니다.

**뉴스레터 확인.** 뉴스레터 양식을 작성하기 시작하면 구독하는 사람이 실제 사람인지 확인하기 위해 브라우저가 `challenges.cloudflare.com`에서 Cloudflare Turnstile을 로드합니다. Cloudflare는 IP 주소와 브라우저 정보를 받습니다.

**구매 유입 기록.** 사이트에 도착하면 브라우저는 첫 방문 기록인 `tablepro:attribution`을 로컬 저장소에 90일간 보관합니다. 방문 출처(따라온 링크의 `ref` 또는 `utm_*` 태그나 유입 사이트), 처음 방문한 페이지 및 시간이 포함됩니다. 구매를 시작하면 결제 요청과 함께 전송됩니다. 운영자의 서버는 방문 출처를 결제의 메타데이터로 {merchant}에 전달하고, 결제 후 주문과 함께 보관하며, 결제 시작과 결제 이벤트와 함께 PostHog에 보냅니다. 처음 방문한 페이지와 시간은 보관하지 않습니다.

**문서.** docs.tablepro.app의 문서는 Mintlify가 호스팅합니다. Mintlify는 페이지마다 IP 주소와 브라우저 정보를 받으며, 페이지는 Google Fonts에서 글꼴을 불러옵니다. 탐색 표시줄에는 리포지토리의 별 수가 표시되며, 브라우저가 이를 GitHub API에서 가져옵니다. 따라서 GitHub도 IP 주소와 브라우저 정보를 받습니다. 이 요청은 쿠키를 설정하지 않습니다. 문서는 이 사이트에서 선택한 답변을 읽을 수 없으므로 쿠키 질문을 따로 표시합니다. 문서에서 **Allow**를 선택하기 전에는 쿠키를 설정하지 않고 방문자 ID도 저장하지 않습니다. 허용하면 Google Analytics가 `_ga` 및 `_ga_<ID>` 쿠키를 설정해 문서 방문을 측정하고, Mintlify는 집계를 위해 무작위 방문자 ID인 `mintlify_anonymous_id`를 로컬 저장소에 저장합니다. 문서 바닥글의 **Cookie settings**에서 답변을 바꿀 수 있으며, 거부하면 둘 다 삭제됩니다. 법적 근거: 동의.

**언어 및 지역 할인.** 브라우저 언어에 사이트가 제공하는 언어가 없을 때 사용자 언어로 된 페이지를 제안하고 결제 시 적용될 지역 할인을 표시하기 위해, 사이트는 Cloudflare(`/cdn-cgi/trace`)와 운영자의 서버에 연결이 어느 국가에서 오는지 묻고 기기의 시간대를 읽을 수 있습니다. 두 요청 모두 쿠키를 포함하지 않으며 페이지는 응답 내용을 보관하지 않습니다. 법적 근거: 정당한 이익.

사이트를 읽는 것만으로는 자체 쿠키가 설정되지 않습니다. 공개 사이트의 뉴스레터 구독, 결제 및 할인 코드 요청은 인증 정보를 제외하므로 계정 포털 쿠키를 보내거나 응답의 쿠키를 수락하지 않습니다. 계정 포털 페이지를 여는 것은 별도 작업이며, 그곳에서 로그인하면 아래의 포털 쿠키가 설정됩니다. 사이트가 브라우저에 보관하는 모든 항목은 [쿠키 및 브라우저 저장소](#cookies)에 나와 있습니다.

## 구매 {#purchases}

라이선스는 merchant of record이자 재판매자인 {merchant}(Polar Software, Inc.)가 판매합니다. 구매에는 {merchant}의 구매자 약관과 개인정보 처리방침이 적용됩니다. {merchant}는 결제를 처리하고 판매세 또는 VAT를 계산하고 납부하며 영수증과 청구서를 보내고 결제 문제와 분쟁을 처리합니다. 이름, 이메일 주소, 청구 주소 및 결제 정보를 수집합니다. 운영자는 카드 정보 전체를 볼 수 없습니다.

결제를 시작하면 운영자의 서버는 구매 내용, 구매하는 페이지의 언어, 방문 출처([웹사이트](#website) 참고), IP 주소를 {merchant}에 알려줍니다. {merchant}는 IP 주소로 세금과 통화를 정합니다. 운영자는 {merchant}에서 이메일 주소, 입력한 이름과 청구 주소, 구매 내용, 금액, 주문 및 구독 ID, 이후 갱신·취소·환불 같은 변경 정보를 받습니다. 주문마다 이메일 주소, 청구 국가, 금액을 보관합니다.

로그인하지 않고 구매하면 구매에 사용한 이메일 주소의 TablePro 계정으로 들어갑니다. 계정이 없으면 새로 만들어지며 처음 로그인할 때까지 인증되지 않은 상태로 남습니다. [계정 포털]({account})에서는 구독의 결제 주기나 좌석 수를 바꾸고, 구독을 취소하거나 재개하고, 환불을 요청할 수 있습니다. 취소할 때 선택한 사유와 작성한 의견은 {merchant}에 전달되어 구독과 함께 보관됩니다. 카드, 청구서, 세금 정보 및 청구 주소는 [{merchant} 고객 포털]({portal})에 있으며, 계정 포털에서 열 수 있습니다. 환불은 [환불 정책](/ko/refund-policy)에, 라이선스의 허용 범위는 [이용약관](/ko/terms)에 설명되어 있습니다.

## 계정 포털 {#account}

account.tablepro.app의 [계정 포털]({account})에서 TablePro 계정의 라이선스, 기기, 결제, 팀을 관리합니다. 웹사이트처럼 Cloudflare 뒤에 있는 운영자의 서버에서 실행됩니다.

**계정.** 계정은 한 사람에게 속하며 이메일 주소로 식별합니다. 계정에는 그 주소, 설정한 이름과 언어, 로그인 방법, 로그인된 기기, 라이선스와 주문, 소속 팀과 역할 및 좌석, 그리고 로그인, 새 기기, 팀 변경 같은 계정 변경을 각 변경을 만든 요청의 IP 주소 및 브라우저와 함께 기록한 감사 로그가 담깁니다. 이메일은 계정의 언어로 보내드립니다.

**로그인.** 링크와 6자리 코드를 이메일로 보내드립니다. 링크는 한 번만 사용할 수 있고, 코드는 5번까지 시도할 수 있으며, 둘 다 15분 후 만료됩니다. 패스키를 추가할 수도 있습니다. 패스키마다 공개 키, 붙인 이름, 기기 간 동기화 여부, 추가 시간과 마지막 사용 시간을 저장합니다. Apple, GitHub 또는 Google로 로그인할 수도 있습니다. 이 경우 제공업체는 사용자의 ID와 인증된 이메일 주소를, Apple은 처음에 이름도 운영자에게 알려줍니다. ID와 주소는 계정과 함께 저장하며, Apple의 경우 토큰을 암호화해 보관하고 Apple 연결을 해제하거나 계정을 삭제하면 Apple에서 취소합니다. 제공업체의 주소가 기존 계정의 것이면 연결하기 전에 해당 계정으로 확인용 링크와 코드를 보냅니다. 단, Google이 그 주소를 관리하는 경우(Gmail 또는 Google Workspace)는 제외합니다.

**팀.** 누군가를 팀에 초대하면 그 사람의 이메일 주소, 역할, 초대에 좌석이 포함되는지를 저장하고 7일 동안 유효한 링크를 보냅니다. 소유자와 관리자는 팀 구성원의 이름과 이메일 주소, 초대, 팀의 감사 로그를 볼 수 있습니다. 감사 로그에는 초대한 주소를 포함해 팀에서 누가 무엇을 바꿨는지 표시되지만 IP 주소나 브라우저는 표시되지 않습니다. 구성원은 팀, 팀의 플랜, 좌석 수, 자신의 역할을 볼 수 있습니다.

**데이터.** 설정에서 이름, 이메일 주소, 언어를 바꾸고, 로그인 방법을 추가하거나 제거하고, 계정 데이터를 JSON 파일로 다운로드하고, 계정을 삭제할 수 있습니다. 다른 구성원이 있는 팀의 소유자인 동안에는 삭제할 수 없습니다. 삭제하면 로그인 방법, 기기, 라이선스, 팀 멤버십, 혼자만 있는 팀이 삭제되고 구독은 환불 없이 종료됩니다. 삭제 후 보관하는 정보는 [보관 기간](#retention)에 나와 있습니다.

**포털이 로드하는 것.** 포털은 Google Analytics, Cloudflare Web Analytics 등 어떤 분석 스크립트도 로드하지 않으며 쿠키에 관해 묻지 않습니다. [웹사이트](#website)에 설명된 Crisp 실시간 채팅을 표시하며, 포털에서 구매하면 페이지 위에 {merchant} 결제 창이 열립니다. 오류와 로딩 시간은 Grafana Faro로 Grafana Cloud에 보고합니다. 보고하는 항목은 오류, 오류가 발생한 화면(링크의 토큰이 들어 있을 수 있는 전체 주소는 보내지 않음), 브라우저와 운영체제, 방문마다 정해지는 임의 ID입니다.

## 뉴스레터 {#newsletter}

릴리스 노트를 구독하면 먼저 구독한 페이지의 언어로 확인 링크를 이메일로 보냅니다. 링크는 7일 동안 유효하며 한 주소에는 하루 최대 3개까지 보냅니다. 확인하면 주소가 운영자의 이메일을 보내는 서비스인 Resend의 뉴스레터 목록에 추가됩니다. 모든 뉴스레터에 구독 해지 링크가 있으며 Resend가 처리합니다. 구독 해지 후에는 뉴스레터를 보내지 않습니다. 주소 자체의 삭제도 원하면 이메일로 요청하세요. 양식은 [웹사이트](#website)에 설명된 대로 Cloudflare Turnstile이 확인합니다.

이전 서버에서 옮겨 올 때, 그 메일링 리스트에서 구독을 해지하지 않은 주소는 확인 여부와 관계없이 모두 구독 상태로 이 목록에 추가되었습니다. 이전 서버는 구매자, 라이선스 보유자, 베타 신청자의 주소도 목록에 추가해 이메일을 보냈습니다. 구독을 해지한 주소는 해지 상태로 옮겨졌고, 이메일이 반송되었거나 스팸으로 신고된 주소는 대신 Resend의 수신 차단 목록에 추가되어 뉴스레터가 가지 않습니다.

## 쿠키 및 브라우저 저장소 {#cookies}

공개 웹사이트를 읽는 것만으로는 자체 쿠키가 설정되지 않습니다. 뉴스레터 구독, 결제 및 할인 코드 요청은 인증 정보를 제외하며 포털 쿠키를 설정하지 않습니다. 계정 포털에 로그인하거나 로그인을 시작하면 아래의 필수 쿠키 하나가 설정됩니다. Cloudflare Web Analytics는 쿠키를 설정하거나 브라우저에 정보를 저장하지 않습니다. Google Analytics 쿠키는 허용하기 전까지 설정하지 않습니다. Crisp는 채팅 로딩 후 모든 페이지에 쿠키를 설정합니다. 여기에 나열된 정보는 광고에 사용되거나 판매되지 않습니다.

- **`_ga` 및 `_ga_<ID>`**(Google Analytics 쿠키, 최대 2년, 분석 허용 시에만): 브라우저의 임의 식별자와 현재 방문 상태입니다. 거부하거나 나중에 응답을 변경하면 삭제됩니다. 법적 근거: 동의.
- **`tablepro:analytics-consent`**(로컬 저장소, 사용자가 지울 때까지): 분석 질문에 대한 응답을 저장해 페이지마다 다시 묻지 않게 합니다. 계정 포털은 분석을 하지 않으므로 이 질문을 하지 않으며 응답도 읽지 않습니다. 법적 근거: 선택을 존중하기 위해 반드시 필요.
- **`tablepro:attribution`**(로컬 저장소, 90일): [웹사이트](#website)에 설명된 첫 방문 기록입니다. 사용자 식별자는 없으며 결제 요청과 함께만 전송되며, 서버는 방문 출처를 {merchant}에 전달합니다. 법적 근거: 정당한 이익.
- **`theme`**(로컬 저장소, 사용자가 지울 때까지): 선택한 라이트, 다크 또는 시스템 화면 모드를 저장합니다. 계정 포털은 별도로 저장합니다. 법적 근거: 정당한 이익.
- **`tablepro:language`**(로컬 저장소, 사용자가 지울 때까지): 언어 메뉴나 언어 표시줄에서 선택한 언어와 제안을 닫은 언어를 저장하여 다시 제안하지 않습니다. 법적 근거: 정당한 이익.
- **`mintlify_anonymous_id`**(docs.tablepro.app의 로컬 저장소, Mintlify가 설정, 문서에서 Google Analytics를 허용한 경우에만): [웹사이트](#website)에 설명된 방문자 ID입니다. 거부하면 삭제됩니다. 문서는 자체 `tablepro:analytics-consent` 답변을 따로 저장합니다. 법적 근거: 동의.
- **`crisp-client/`로 시작하는 쿠키**(Crisp, 예: `crisp-client/session/…`, 6개월, 재방문 시 갱신, 채팅 로딩 후 모든 페이지에 설정): 페이지와 방문 간에 채팅과 대화를 유지합니다. 법적 근거: 모든 페이지에서 지원을 제공하기 위한 정당한 이익.
- **`__Host-tp_session`**(계정 포털 쿠키, 로그인부터 30일): 로그인 상태를 유지합니다. 로그인 전에는 패스키, Apple, GitHub, Google 또는 앱에서의 로그인이 진행되는 동안에만 최대 10분간 설정됩니다. 로그아웃하면 삭제됩니다. 공개 사이트의 뉴스레터, 결제 및 할인 코드 요청은 인증 정보를 제외하며 이 쿠키를 받지 않습니다. 법적 근거: 반드시 필요.
- **`locale`, `context` 및 `sign-in-return-to`**(계정 포털 로컬 저장소): 로그인 전에 포털에서 고른 언어와 마지막으로 연 것이 개인인지 팀인지(둘 다 지울 때까지), 그리고 이메일의 로그인 링크를 연 뒤 돌아갈 페이지(15분)입니다. 법적 근거: 정당한 이익.
- **`com.grafana.faro.session`**(계정 포털 세션 저장소, 탭을 닫을 때까지): 포털 오류 보고에 쓰는 방문별 임의 ID입니다. 법적 근거: 정당한 이익.

분석에 대한 응답은 모든 페이지의 푸터에 있는 **쿠키 설정** 또는 아래에서 언제든 변경하거나 철회할 수 있습니다.

## 보관 기간 {#retention}

- **사용 보고서와 분석 이벤트**: 운영자의 서버는 PostHog에 전달한 뒤 사본을 보관하지 않습니다. PostHog에서의 보관 기한은 정하지 않았습니다. 계정을 삭제하면 해당 PostHog 프로필과 이벤트가 1시간 뒤 삭제됩니다.
- **이전 서버의 기록**: 이전 서버의 데이터베이스 전체 사본을 아카이브에 기한 없이 보관합니다. 여기에는 이메일 주소와 이름이 포함된 라이선스, 주문, 팀 멤버, 라이선스로 활성화된 Mac과 그 이름, 뉴스레터 구독자와 베타 신청자, 보낸 이메일의 기록, 그리고 이전 서버가 보관하던 사용 보고서와 라이선스 요청 로그(IP 주소 포함)가 들어 있습니다.
- **기기**: 사용하는 동안 보관합니다. 180일 동안 통신하지 않은 기기는 유효한 오프라인 파일이 남아 있지 않으면 제거하며, 제거된 기기는 1년 뒤 삭제합니다.
- **계정 감사 로그**: 계정이 있는 동안 사용자가 한 각 변경의 IP 주소 및 브라우저와 함께 보관합니다. 계정을 삭제하면 이메일 주소와 사용자 작업의 IP 주소 및 브라우저가 로그에서 제거되며, 각 변경의 기록 자체는 남습니다.
- **주문**: 세금 및 회계를 위해 보관합니다. 계정을 삭제하면 주문에서 이메일 주소와 계정이 제거됩니다.
- **{merchant}, Resend 및 Apple의 알림**: 180일. {merchant}의 알림에는 이름, 이메일 주소, 청구 주소가 들어 있으며, 계정을 삭제하면 구매에 관한 알림에서는 이 정보가 더 일찍 제거됩니다.
- **Team Library**: 항목이 변경되거나 삭제될 때까지. 삭제한 항목은 90일 동안 보관합니다. 라이브러리는 팀과 함께 삭제되며 라이선스가 끝난 뒤에도 남습니다.
- **로그인 링크와 코드**: 15분 후 만료되며 7일 뒤 삭제됩니다. 포털 세션은 30일 동안 유지됩니다. 앱의 로그인 상태를 유지하는 토큰은 앱이 마지막으로 사용한 때부터 90일 후 만료되며, 그로부터 30일 뒤 삭제됩니다.
- **삭제된 계정**: 계정, 로그인 방법, 기기, 라이선스, 팀 멤버십은 즉시 삭제합니다. 주문과 감사 로그는 위에서 설명한 대로 남습니다. 이전 서버가 보관하던 사용자에 관한 정보는 위에서 설명한 아카이브에 남습니다.
- **뉴스레터**: 확인 링크와 그 링크를 받은 주소는 링크가 만료되고 7일 뒤 삭제합니다. 확인된 주소와 이전 서버에서 옮겨 온 주소는 요청에 따라 삭제할 때까지 Resend의 목록에 남으며, 구독 해지 후에는 뉴스레터가 가지 않도록 구독 해지 상태로 보관됩니다.
- **Google Analytics**: 사용자 수준 및 이벤트 수준 데이터는 2개월이며 운영자의 속성에서 사용하는 Google의 기본 보관 기간입니다. 쿠키는 최대 2년 유지되거나 분석을 거부하면 삭제됩니다.
- **Cloudflare Web Analytics**: 최근 6개월의 페이지 조회 집계를 제공합니다. 브라우저에는 저장되지 않습니다.
- **실시간 채팅 및 지원 이메일**: 삭제할 때까지 Crisp 및 운영자의 메일함에 보관합니다. 대화와 이메일 삭제를 요청할 수 있습니다.
- **웹 서버 로그**: 보안과 문제 해결을 위해 보관합니다. 아직 고정된 기간을 정하지 않았습니다.
- **운영자 서버의 로그와 트레이스, 포털 오류 보고**: Grafana Cloud에서 14일.

**캘리포니아 주민.** California Consumer Privacy Act는 수집하는 개인정보를 알 권리, 삭제를 요청할 권리, 판매를 거부할 권리 및 이러한 권리 행사로 차별받지 않을 권리를 부여합니다. 운영자는 개인정보를 판매하지 않습니다.

## 보안 {#security}

앱, 웹사이트, 계정 포털 및 운영자의 서버 간 통신은 HTTPS를 사용합니다. TablePro 계정에는 비밀번호가 없습니다. 로그인 링크와 코드, 앱의 로그인 상태를 유지하는 토큰, 팀 API 토큰은 해시로 저장됩니다. 다만 로그인 링크와 코드를 이메일로 보내는 작업은 작업이 삭제될 때까지 이를 평문으로 보관하며, 작업은 이메일을 보낸 지 하루 뒤, 전송을 포기한 경우 7일 뒤에 삭제됩니다. 링크와 코드는 모두 요청한 지 15분 뒤에 더 이상 작동하지 않습니다. 시스템 접근 권한은 운영자({publisherName})와 [데이터 수신 대상](#sharing)에 나열된 서비스 제공업체에게만 주어집니다. 완벽하게 안전한 시스템은 없습니다. 취약점은 [보안 페이지](/ko/security#report)의 안내에 따라 신고하거나 [{email}](mailto:{email})로 이메일을 보내주세요.
