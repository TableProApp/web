本政策涵盖 Mac 版 TablePro、iPhone 和 iPad 版 TablePro、位于 tablepro.app 的网站、位于 docs.tablepro.app 的文档，以及位于 account.tablepro.app 的账户门户。它描述各产品目前实际发送和存储的信息。两款应用均采用 AGPLv3 开源，您可在 [TablePro 仓库]({github})中查看发送下列数据的代码。

## 概要 {#summary}

- Mac 应用会发送使用数据。该功能默认开启，可以关闭。iPhone 和 iPad 应用仅在您开启后发送使用情况报告。
- 登录 TablePro 账户或激活许可证密钥后，Mac 应用会将您的 Mac 连同名称登记到我们的服务器，并定期向服务器核对您的方案。
- 您运行的查询、结果和密码不会发送给 TablePro。例外是您自行选择发布到 Team Library 的连接设置（从不包含密码）和已保存查询。
- AI 请求从 Mac 应用直接发送至您设置的 AI 提供商，不经过我们。
- 从支持 TablePro 账户的版本起，Mac 应用直接向我们位于欧盟的产品分析服务 PostHog 发送使用数据，PostHog 因此会收到您的 Mac 的 IP 地址，并据此推算大致位置。更早的版本以及 iPhone 和 iPad 应用将使用报告发送到我们的服务器，由服务器转发给 PostHog，不附带 IP 地址。您的账户会保存对账户所做更改的日志，例如登录和新设备，并附有发起每项更改的请求的 IP 地址和浏览器。
- 网站使用不设置 Cookie 的 Cloudflare Web Analytics 统计页面浏览量。网站也加载 Google Analytics，但只有获得您的允许才设置 Cookie。每个页面还会加载在线聊天服务 Crisp，它会设置自己的 Cookie。
- account.tablepro.app 上的账户门户不加载任何分析脚本。它设置一个保持登录的 Cookie，您可以在其设置中下载账户数据或删除账户。
- 购买由我们的 merchant of record {merchant} 负责销售。

## 谁负责处理 {#controller}

发布 TablePro 应用和本网站的{publisherCountry}{publisherCity}个人开发者 {publisherName} 是此处所述个人数据的责任方（数据控制者）。如对本政策或您的数据有疑问，请发送邮件至 [{email}](mailto:{email})。

## Mac 版 TablePro {#mac-app}

### 使用数据 {#mac-usage-report}

从支持 TablePro 账户的版本起，Mac 应用直接向我们位于欧盟的产品分析服务 PostHog（`eu.i.posthog.com`）发送使用数据。**该功能默认开启，发送第一个事件前不会征求同意**。要关闭，请进入**设置 > 通用 > 隐私**（Settings > General > Privacy）并取消勾选**共享使用数据**（Share usage data）。关闭期间，应用不向 PostHog 发送任何内容；如果应用启动时该设置已关闭，则根本不会启动 PostHog 的库。

应用会在以下情况发送事件：

- 运行期间每天一次，附带已打开连接的数据库类型名称（如 PostgreSQL）和已打开的连接数量；
- 首次尝试连接、首次成功连接和首次运行查询时，各附带数据库类型；
- 应用提示某项付费功能不可用时，每次运行应用每项功能一次，附带该功能和原因（例如未登录）；
- 点击升级时，附带您在应用中点击的位置；
- 登录时，附带登录方式（在应用中登录、使用许可证密钥，或兑换 Mac 上已有的密钥），以及退出登录时。

PostHog 的库会为每个事件添加 Mac 的型号、屏幕尺寸、时区和语言、是否使用 Wi-Fi、应用的版本、构建号和 Bundle ID、macOS 版本、库的版本以及随机的会话 ID。PostHog 会随每个请求收到您的 Mac 的 IP 地址，并据此推算大致位置，例如国家和城市。该设置开启期间，库还会从 PostHog 获取其配置和功能标志（`/config` 和 `/flags`）。

登录之前，事件携带库在您的 Mac 上生成的随机 ID，PostHog 不会为其建立个人档案。登录后，事件改为携带您的账户 ID，PostHog 中该账户的档案保存应用和 macOS 版本、处理器架构以及应用语言，从而把您的安装与登录和购买联系起来。退出登录后会启用新的随机 ID。应用不再发送机器 ID、许可证激活状态或更新设置。

支持 TablePro 账户之前的版本则在同一设置下，于启动约十秒后向 `api.tablepro.app` 发送使用情况报告，随后在运行期间每天发送一次。报告包含：

- 机器 ID：Mac 硬件 UUID 的 SHA-256 哈希值（UUID 本身从不发送）；
- 平台、应用版本、macOS 版本、处理器架构和应用语言；
- 已打开连接的数据库类型名称（如 PostgreSQL）和已打开的连接数量；
- 是否已激活许可证；
- 首次尝试连接和首次成功连接的日期和时间；
- 更新设置（安装方式及检查频率）。报告抵达时，我们的服务器会丢弃这些设置。

事件和报告都从不包含主机名、用户名、密码、查询或行数据。

我们的服务器既不保存报告，也不保存发送报告的 IP 地址。服务器将报告作为关于机器 ID 的事件转发给 PostHog，附上 Cloudflare 为您的连接给出的国家，不附带许可证密钥或 IP 地址；PostHog 不会据此建立个人档案。由于您的账户以相同的机器 ID 记录设备，来自您登录过或激活过许可证的 Mac 的报告可与您的账户关联。

### 许可证验证 {#mac-license}

Mac 应用仅在您输入许可证密钥后联系许可证服务器。它会在激活时、距上次验证至少 {revalidateDays} 天后的启动时，以及此后每隔 {revalidateDays} 天验证。每次验证发送：

- 许可证密钥；
- 上述机器 ID；
- macOS 中设置的 Mac 名称（其中经常包含您的姓名）；
- 应用版本和 macOS 版本。

停用某台 Mac 时只发送许可证密钥和机器 ID。

服务器将每台已激活的 Mac 保存为持有许可证的账户的设备：包括机器 ID 和名称、应用和 macOS 版本，以及最后一次联系服务器的时间。激活和停用 Mac 会连同请求的 IP 地址和用户代理记录在该账户的审计日志中；定期验证不会记录。账户门户按名称列出您的设备。如果无法连接服务器，付费功能可自上次成功验证起继续使用 {graceDays} 天。

### TablePro 账户 {#mac-account}

从支持 TablePro 账户的版本起，您使用 [TablePro 账户](#account)而不是许可证密钥登录 Mac 应用。应用会在浏览器窗口中打开登录页面，您也可以在那里输入登录邮件中的代码。登录后，应用将您的 Mac 登记为账户的设备：上文所述的机器 ID、Mac 名称、平台，以及应用和 macOS 版本。之后，应用在运行期间每天从我们的服务器获取一次以签名文件形式提供的方案；有了该文件，付费功能在无法连接服务器时最多可继续使用 {offlineDays} 天。保持应用登录的令牌仅保存在该 Mac 的 macOS 钥匙串中，即使开启了密码同步，也不会通过 iCloud 钥匙串同步。

Mac 上已有的许可证密钥会一次性换成持有该密钥的账户的登录，然后从 Mac 上删除。180 天未联系服务器的设备会被移除。您可以在应用或账户门户中移除设备；某台 Mac 首次使用您的许可证时，我们会发邮件通知您。

### Team Library {#library}

Team Library 是 Team 许可证的功能。当您在连接上选择**分享 > 发布到团队库…**（Share > Publish to Team Library…），或在 Favorites 侧边栏选择**将已保存的查询发布到团队…**（Publish Saved Queries to Team…）时，Mac 应用将您发布的内容上传至服务器：

- 连接设置：主机、端口、数据库名、用户名、SSH 和 SSL 设置、驱动选项、启动命令、Tunnel Command 设置、Safe Mode 级别和 AI 设置，但绝不包含密码；
- 已保存查询：名称、SQL 文本、关键词和文件夹。

从支持 TablePro 账户的版本起，每位拥有席位的成员的 Mac 应用会在启动时、每 15 分钟以及每次发布后下载库的更改。发布时只发送有变化的内容，并只删除该 Mac 发布过但已不再拥有的项目。如果其他人先修改了某个项目，应用会询问保留哪一份，并显示每条团队查询的最后修改者。支持 TablePro 账户之前的版本在启动时下载库，最多每周一次；执行发布的 Mac 会在发布后立即重新下载。从这些版本再次发布会替换此前发布的内容。账户门户中的 Library 会向可读取库的成员显示每个项目及最后修改者的姓名，所有者和管理员可在其中删除项目。已删除的项目会在我们的服务器上保留 90 天，以便每台 Mac 同步删除。许可证结束后，库仍保留在我们的服务器上，直到团队所有者删除团队，库也随之删除。

另一项 Team 功能 Team Catalog 会将不含密码的连接文件写入您选择的共享文件夹，不经过我们的服务器。

### 更新和插件 {#mac-updates}

- **更新检查**。Mac 应用每天从 GitHub（`raw.githubusercontent.com`）下载一次更新源。除所有网络请求都会携带的 IP 地址和含应用版本的 User-Agent 外，请求不会发送其他 Mac 信息。要关闭，请进入**设置 > 通用 > 软件更新**（Settings > General > Software Update）并取消勾选**自动检查更新**（Automatically check for updates）。更新本身也从 GitHub 下载。
- **插件目录**。应用启动时和打开插件设置时，会从 GitHub 下载可用驱动和主题列表。没有关闭此行为的设置。您安装的驱动和主题从 GitHub 下载，插件浏览器通过 GitHub API 获取下载次数。

GitHub 会随这些请求收到您的 IP 地址，这些请求适用 GitHub 自身的隐私声明。

### 您选择使用的服务 {#mac-third-parties}

只有设置后，Mac 应用才会直接向以下服务发送数据，从不经过 TablePro：

- **您的数据库、SSH 服务器和代理**接收连接向其发送的信息。
- **AI 提供商**。添加提供商并使用 AI 助手或行内建议时，请求直接发送给该提供商或 Mac 本地运行的模型。默认包含数据库类型和名称、结构中的表和列定义，以及当前查询。仅在您开启相应选项后才发送结果行。适用提供商自身的条款。添加 GitHub Copilot 会从 npm 下载其语言服务器，其“向 GitHub 发送遥测数据”（Send telemetry to GitHub）设置默认开启。
- **登录服务**：连接使用时的 Microsoft Entra ID、Google、Amazon Web Services 和 Cloudflare Access。
- **Apple Maps**：在地图上显示结果时提供地图瓦片。
- **DuckDB**：查询首次使用某个扩展时提供该扩展。
- **MCP 客户端**。MCP 服务器默认关闭。您开启它，或已设置的 MCP 客户端启动 TablePro 桥接程序或与其配对时，它会启动，且仅监听 Mac 本地（127.0.0.1）。连接的 AI 客户端（如 Claude 或 Cursor）接收其请求的结果，并按自身条款发送至其服务。
- **您添加的 MCP 服务器**。AI 会话会将您批准的工具调用及其参数发送至该服务器。

### 留在 Mac 上的数据 {#mac-local}

密码保存在 macOS 钥匙串中。连接列表、查询历史、Query Insights、Data Rewind 快照、设置和打开的选项卡存储在 Mac 上。应用引用磁盘上的 SSH 密钥，不会复制它们。支持 TablePro 账户之前的版本不包含崩溃报告工具或第三方分析库。从支持 TablePro 账户的版本起，应用包含 PostHog 的库，用于发送上文所述的使用数据。该库包含 PostHog 的崩溃报告工具，但应用将其保持关闭，因此不会发送崩溃报告。该库将其随机 ID、配置和尚未发送的事件保存在 `~/Library/Application Support/com.TablePro` 下的文件中。

## iPhone 和 iPad 版 TablePro {#ios-app}

**除非您开启共享使用数据（Share Usage Data），否则不会向 TablePro 发送任何信息**。您可在首次启动时或之后的**设置 > 隐私**（Settings > Privacy）中开启。开启后，应用每天向与支持 TablePro 账户之前的 Mac 应用版本相同的服务器发送一次报告，服务器以相同方式将报告转发给 PostHog，不附带其 IP 地址。报告包含 Apple 为设备上的应用分配的标识符的 SHA-256 哈希值、平台、应用和 iOS 版本、处理器架构、应用语言、已打开连接的数据库类型名称、已打开的连接数量，以及首次尝试连接、首次成功连接和首次运行查询的日期和时间。不包含更新设置，并始终报告未激活许可证，因为应用没有这两项内容。

应用不会发起许可证验证、更新检查或插件请求。除可选报告外，它仅连接您的数据库和 SSH 服务器、开启 iCloud Sync 时的 Apple iCloud，以及 SQL Server 连接使用 Microsoft Entra ID 登录时的 Microsoft。

在设备上，密码和粘贴的 SSH 密钥保存在钥匙串中，证书从不同步。查询历史留在设备上。连接会加入设备的 Spotlight 索引，以便搜索。查询运行期间，除非您开启**设置 > 实时活动 > 隐藏查询**（Settings > Live Activities > Hide Query），其实时活动会在锁屏和展开的灵动岛上显示 SQL。

如果您在 iPhone 或 iPad 设置中选择与应用开发者共享分析数据，Apple 可能通过 App Store Connect 向我们提供崩溃报告和使用统计。应用本身没有崩溃报告工具或第三方分析库。

## iCloud Sync 和 Handoff {#icloud}

iCloud Sync 在 Mac、iPhone 和 iPad 上均默认关闭，直到您开启。开启后，记录会发送至您自己 iCloud 账户内的私有数据库（容器 `iCloud.com.TablePro`）。TablePro 无法读取它们。

- 在 Mac 上，您可选择同步连接、分组和标签、设置、SSH 配置、凭据配置（名称和用户名，从不包含密码）、表和数据库收藏、已保存查询（包括 SQL 文本）以及表文件夹。连接记录包含主机、端口、用户名、数据库名、SSH 和 SSL 设置、启动命令、连接前脚本和 AI 规则。查询历史、Data Rewind 快照和密码来源从不同步。
- iPhone 和 iPad 同步连接、分组和标签。
- 密码仅在您同时开启 Mac 上 Sync Categories 中的**密码**（Passwords），或 iPhone 和 iPad 上的**同步密码**（Sync Passwords）后同步，使用 iCloud 钥匙串。在 Mac 上，这也会同步 TablePro 保存在钥匙串中的其他机密信息，如 AI 提供商密钥和许可证密钥。从支持 TablePro 账户的版本起，许可证密钥在兑换为登录后即被删除，保持应用登录的令牌也从不同步。

Mac 上的 iCloud Sync 属于 Starter 或 Team 许可证功能，在 iPhone 和 iPad 上免费。

Handoff 通过 Apple 在您的设备之间传递当前连接的 ID 和打开的表名。没有打开表时，传递连接名称；连接没有名称时则传递主机。不会发送设置或凭据。

## 网站 {#website}

**托管**。网站和账户门户运行在我们的服务器上，由 Cloudflare 提供前置服务。与任何网络服务器一样，它们会收到您的 IP 地址、浏览器 User-Agent 和请求的每个页面地址。

**Cloudflare Web Analytics**。Cloudflare 在网站页面中加入 Web Analytics 脚本；账户门户不运行该脚本。浏览器从 `static.cloudflareinsights.com` 加载它，每次浏览页面都会向 Cloudflare 报告页面、链接来源网站、加载耗时，以及浏览器、操作系统和设备类型。Cloudflare 会补充连接所属国家。脚本不设置 Cookie，也不在浏览器中保存信息；Cloudflare 声明不会使用 IP 地址或浏览器信息对您进行指纹识别。Cloudflare 向我们提供页面或国家的浏览量等汇总数据，不提供每位访客的记录。合法依据：合法利益。

**Google Analytics**。网站在每个页面以 Consent Mode 加载 Google Analytics。在您于 Cookie 提问中选择**允许**之前，它不设置 Cookie，仅为每个页面向 Google 发送无 Cookie 信号，不在设备上存储标识符。允许后，Google Analytics 设置 `_ga` 和 `_ga_<ID>` Cookie，统计页面浏览、下载点击和开始结账等访问行为。广告存储、广告个性化和广告用户数据始终被拒绝。Google 声明 Google Analytics 4 不记录或存储 IP 地址。我们的 Google Analytics 媒体资源使用 Google 默认保留期：用户级和事件级数据收集后两个月由 Google 删除。保存汇总而非标识符的标准报告不受影响。合法依据：您对 Cookie 的同意。

**在线聊天**。网站和账户门户的每个页面都显示聊天提供商 Crisp 的按钮。页面加载完成后，浏览器从 `client.crisp.chat` 加载 Crisp 脚本，Crisp 会设置 [Cookie 和浏览器存储](#cookies)中所述的 Cookie。Crisp 收到 IP 地址、浏览器信息、浏览的页面地址和您撰写的消息，并在您开始对话后保留 IP 地址。我们向 Crisp 提供页面语言。您登录账户门户时，我们还会向 Crisp 提供您账户的邮箱地址和账户 ID，以便将对话与您的账户关联。我们不向 Crisp 提供您的其他信息。Crisp 位于法国。

**结账脚本**。当您将指针移至购买按钮或用 Tab 键聚焦时，浏览器从 jsDelivr（`cdn.jsdelivr.net`）加载 {merchant} 的结账脚本。jsDelivr 会收到 IP 地址和浏览器信息。只有点击后，结账页面才从 {merchant} 打开。

**订阅邮件验证**。当您开始填写邮件订阅表单时，浏览器会从 `challenges.cloudflare.com` 加载 Cloudflare Turnstile，以确认订阅者是真人；Cloudflare 会收到您的 IP 地址和浏览器信息。

**购买归因**。首次到访网站时，浏览器在本地存储中保存名为 `tablepro:attribution` 的首访记录，期限为 90 天：访问来源（所点击链接中的 `ref` 或 `utm_*` 标签，或来源网站）、进入的页面和时间。开始购买时，该记录随结账请求发送。我们的服务器将访问来源作为结账元数据传给 {merchant}，在您付款后与订单一起保存，并随结账和付款事件发送给 PostHog。进入的页面和时间不会保存。

## Cookie 和浏览器存储 {#cookies}

仅阅读公开网站不会设置网站自身的 Cookie。邮件订阅、结账和优惠码请求不携带凭据，也不会设置门户 Cookie。登录账户门户或开始登录时，会设置以下唯一一个严格必要的门户 Cookie。Cloudflare Web Analytics 不设置 Cookie，也不在浏览器中存储信息。Google Analytics Cookie 在您允许之前不会设置。Crisp 在聊天加载后为每个页面设置 Cookie。此处的信息不用于广告，也不会出售。

- **`_ga` 和 `_ga_<ID>`**（Google Analytics Cookie，最长两年，仅在允许分析时）：浏览器的随机标识符及当前访问状态。拒绝或之后更改回答时会删除。合法依据：同意。
- **`tablepro:analytics-consent`**（本地存储，直至您清除）：保存对分析提问的回答，避免每个页面重复询问。账户门户不进行分析，因此不会询问此问题，也不读取回答。合法依据：履行您的选择所严格必要。
- **`tablepro:attribution`**（本地存储，90 天）：[网站](#website)一节所述的首访记录。不包含您的标识符，仅随结账请求发送，服务器会将访问来源传给 {merchant}。合法依据：合法利益。
- **`theme`**（本地存储，直至您清除）：保存所选浅色、深色或系统主题。账户门户单独保存自己的选择。合法依据：合法利益。
- **`tablepro:language`**（本地存储，直至您清除）：保存您在语言菜单或语言栏中选择的语言，以及您关闭过推荐的语言，以免再次推荐。合法依据：合法利益。
- **`mintlify_anonymous_id`**（docs.tablepro.app 的本地存储，由 Mintlify 设置，仅在您于文档中允许 Google Analytics 时）：[网站](#website)一节所述的访客 ID。拒绝后即删除。文档单独保存自己的 `tablepro:analytics-consent` 回答。合法依据：同意。
- **以 `crisp-client/` 开头的 Cookie**（Crisp，如 `crisp-client/session/…`；六个月，再次访问时续期；聊天加载后每个页面都会设置）：在页面和访问之间保持聊天及对话。合法依据：为每个页面提供支持的合法利益。
- **`__Host-tp_session`**（账户门户 Cookie，自登录起 30 天）：保持登录状态。登录前，仅在通过通行密钥、Apple、GitHub、Google 或应用登录的过程中设置，最长 10 分钟。退出登录会删除它。公开网站的邮件订阅、结账和优惠码请求不携带凭据，也从不会收到它。合法依据：严格必要。
- **`locale`、`context` 和 `sign-in-return-to`**（账户门户本地存储）：登录前在门户中选择的语言、最近打开的是个人还是某个团队（两者均保存至您清除为止），以及打开邮件中的登录链接后要返回的页面（15 分钟）。合法依据：合法利益。
- **`com.grafana.faro.session`**（账户门户会话存储，直至您关闭标签页）：门户错误报告所用的随机访问 ID。合法依据：合法利益。
